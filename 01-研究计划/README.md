# 研究计划

本目录保留用于导师讨论、博士申请和研究启动的简版材料。更新日期：2026-10-22。设计阶段合成敏感性计算已运行；参与者研究、设备实测和伦理审批仍属计划，不代表导师同意或合作资源到位。

本轮同步的核心设计：18 段 45–60 秒同框回放、36 题、三材料组；字幕及 ASR trace 跨条件冻结，正常音视频与惯常助听方式保留。C1 为共享有效性、容量与调度规则的基础调度辅助，C2 再加选择性门控。唯一主要估计 Δ20（C2−C0）报告 95% 区间；次要准确率族 Δ21/Δ10 各报 Bonferroni 97.5% 区间，其余体验结果以描述为主。约 24 人仍为暂定目标；N=24/36/48 的已运行计算是设计敏感性模拟，不是完整 GLMM 功效证明。

正式申请按院校字数与格式裁剪，并据真实资源确认语言、设备和伙伴。简版与提交包共享范围，操作细节以冻结后的同版本协议与参数为准；任何变更同步更新，不能将计划写成既往成果。
