# 导师方向与研究定位

**核验日期：2026-10-22。** 本文为导师讨论提供问题、方法与首年交付的对应关系。导师指导、实验室资源和招募合作仍待实际确认；文献中的研究对象与发现不会作为本项目的既有成果。

## 1. 身份与方向

本项目讨论的导师为南方科技大学设计学院 **LI Xueliang（Sean），李雪亮**。学校教师页面将其研究置于人机交互、机器人交互、情感驱动设计与心理福祉等方向，并体现研究型设计取向 [LI-00]。定位应以其实际论文的方法和问题为依据，不把学校其他教师的成果或实验室新闻中的全部论文归到其名下。

本项目最自然的连接是：**人在具体社会情境中如何理解、协商并控制技术提供的帮助。** 显示眼镜、Jev 和生理传感是可更换的研究媒介，DHH 对话中的信息访问、提示解释与主体性才是首年核心问题。其 Research-through-Design 取向也为原型迭代、参与者解释和设计过程反思提供直接的方法连接 [LI-00, METHOD-02, METHOD-03]。

这一定位将可访问性与社会技术设计相连接：字幕层支持进入对话，补充线索支持理解可观察表达，恢复机制支持继续自主参与。可选日常模块关注佩戴者如何解释自身数据；它与主线共享“帮助应可协商”的问题，但不将 DHH 身份等同于心理健康问题。

### 从方法贴合到具体研究活动

近期论文所体现的共创、多方理解和反思性设计，可以转化为首年可执行活动，而不需要改变研究对象：

| 拟开展活动 | 方法连接 | 应留下的研究材料 |
| --- | --- | --- |
| 邀请 DHH 佩戴者描述重要、困难或不想被解释的会话时刻；以伙伴视角补充情境 | 社会技术关系和多方观点 [LI-01, LI-02] | 情境卡、需要与冲突、参与者对研究者假设的修订 |
| 用同一会话片段比较提示位置、措辞、出现时机和无提示方案 | 共创中的具体媒介和参与者改造 [LI-03] | 带理由的草图、方案差异、拒绝某类提示的记录 |
| 记录原型如何从参与者反馈变为候选池和控制规则 | RtD 的过程与可扩展性 [METHOD-02, METHOD-03] | 版本化原型、决策日志、设计命题及其适用条件 |
| 独立呈现错人、过期或不恰当帮助，回顾参与者如何恢复 | 人与可穿戴帮助的协商 [LI-05]，以及通用人—AI 控制原则 [HCI-08] | 事件轨迹、恢复过程、可接受代价和反例 |
| 在可选日常分支中让本人选择动作、解释事件并决定下一次是否需要支持 | 个人数据的反思性意义 [LI-04] | 自述与传感证据分开的事件卡、被忽略／被接受的提示及原因 |

这些活动只是计划，尚未招募或执行。设计记录应反映真实选择及其变化，而不是在实验结束后补写一条“必然通向最终产品”的故事。

## 3. 不改变核心的整合方式

第一层是**可访问的对话基础**：稳定字幕、会话内说话者标签、保守的屏幕相对空间提示。第二层是**不确定的补充帮助**：对少量合格线索决定显示、延迟或弃答，用户可以关闭或纠正。第三层才是**可选的自身觉察**：在获得相应信号权限后，研究佩戴者如何理解心率变化和自己选定的手部习惯。

三层共享时序与短期上下文，但不共享未经证实的心理标签。自己的心率不能用来判断对话伙伴的态度；他人的停顿或面部变化不能直接变成对方的真实情绪；Jev 不替代感知校验，也不替代用户对经历的解释。

首年主实验不把三层一次全部打开。C0/C1/C2 使用相同字幕基础与冻结候选池，主要比较 C2 对 C0 的解释准确率。RQ4 独立试点、独立同意、独立报告，信号接入失败不会阻止主实验。这样既保留完整研究愿景，也使申请稿有清晰的首年贡献和退出机制。

## 4. 三类贡献如何共同成立

首年拟议贡献分别对应共创设计知识、受控政策评价和失败恢复质性知识。它们共享一个研究原型，但使用不同的证据标准：

1. **共创设计知识：**DHH 成人如何选择、拒绝并解释补充会话线索，以及这些选择如何成为可追溯界面规则。贡献体现在情境、理由、备选和设计命题的连接。
2. **受控政策评价：**在相同字幕层下，完整门控策略相对字幕单独使用的效应，以及相对无可选门控条件的收益和代价。贡献依赖冻结条件与预定分析；提示密度仍是政策机制之一。
3. **失败恢复质性知识：**用户如何从错误、延迟、缺失和不合时宜的帮助中恢复，以及何时选择继续使用、忽略或关闭。贡献依赖具体事件、参与者解释和反例，不以满意度单项替代。

已有研究已建立空间字幕、双方／群组共创与表达性字幕的基础 [HCI-01, HCI-09, HCI-11, HCI-14]。本项目将其推进到有限显示眼镜中的帮助时机、政策比较与恢复控制；完整近邻比较见[文献综述与研究缺口](../07-文献与证据/文献综述与研究缺口.md)。本阶段不以硬件品牌、模型替换或“first-ever”作为新颖性依据。

RtD 与受控实验在这里是互补路径：前者使问题框定、设计选择及可迁移经验清楚可查；后者估计特定条件下的结果差异。若参与者更偏好字幕基线，或门控未产生理解收益，仍可据此修订设计命题并报告有信息量的边界 [METHOD-02, METHOD-03]。

RQ4 后续可扩展为主观意义优先的日常可穿戴研究，但必须证明反馈的可接受性、控制与实际用途；不能仅因捕获到模式就称其为心理标志物。即使发现无益、偏好高度异质或提醒增加负担，仍可形成有根据的设计边界。

## 5. 开题讨论的建议焦点

建议先讨论“哪些帮助值得进入会话”，再讨论具体设备和模型。这样可以在保留商业眼镜原型的同时，使首年问题与导师的设计研究方向形成稳定联系。

| 需要确认的问题 | 希望形成的决定 |
| --- | --- |
| 哪些补充线索具有明确访问价值，哪些涉及不必要的心理推断？ | 首批共创情境、候选类别与排除范围 |
| 共创、受控比较与恢复案例各承担什么贡献？ | 对应研究问题、证据标准和首年最低交付 |
| 原型变化怎样成为可讨论的设计知识？ | 设计日志、带注释案例与版本冻结办法 |
| 何时才启动本人状态分支？ | 信号、伦理、资源与增量问题的进入条件 |
| 哪些结论应进入博士后续阶段？ | 现场长期使用、跨语言或密度匹配的后续研究，而非首年附加承诺 |

## 6. 协作资源与责任边界

- DHH 社群伙伴、可访问研究安排和相关领域共同指导是否可获得。
- 项目应以可穿戴交互、可访问性还是社会技术设计为主要投稿定位。
- 显示眼镜、现成麦克风、研究型 EMG 设备与伦理数据设施的实际资源。
- 研究型设计记录、质性分析和控制实验在首年工作量中的合理比例。
- 日常模块是否值得启动；若启动，是否需要另组参与者、额外方法指导与伦理修订。

这些是待协商的研究条件，不应在申请中写成已获承诺的实验室资源。

尤其需要具备 DHH 社群经验的合作伙伴帮助审查研究语言、材料可访问性与结果解释。若开展生理和肌电分支，再补充相应传感与数据治理指导。李雪亮公开研究的方法契合为讨论提供理由，但不能替代这些具体条件的落实。
