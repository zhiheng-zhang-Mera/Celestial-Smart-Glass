# 数据边界

本公开目录当前只包含说明，不包含任何参与者或真实会话数据。

允许后续加入：明确标记的合成样例、数据字典、获准公开的最小研究资料、来源和许可证说明。任何公开材料都应说明是否用于训练、校准、测试或仅作界面示例，避免数据泄漏。

不提交：原始录音视频、健康 / 肌电轨迹、身份映射、人脸 / 声纹嵌入、私人对话、API 密钥或受限模型权重。`.gitignore` 只是辅助，不使该目录成为受控存储。

数据管理、撤回和留存见[隐私与数据生命周期](../03-系统架构/隐私与数据生命周期.md)及[伦理与参与者材料](../05-实验与评估/伦理与参与者材料.md)。
