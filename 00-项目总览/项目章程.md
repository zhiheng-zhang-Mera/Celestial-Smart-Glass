# 项目章程

版本：`CSG-DRAFT-20261022-v1`。范围状态：拟议研究与工程方案；文档落库不表示导师接受、伦理批准或产品实现。

## 1. 项目问题

在面对面多人对话中，佩戴者需要同时阅读字幕、确定谁在说话、理解可观察的表达方式并保有自主回应的空间。本项目研究：智能眼镜应如何组织这些信息，何时提供辅助，何时保持安静，以及在识别错误或证据不足时怎样让用户继续掌握互动。

项目长期包括理解外部对话与觉察本人状态两个方向，二者共享设备和事件基础设施，但保持数据、解释和研究结论分离。本人心率上升不会成为“对方有敌意”的证据，模型对对方语气的解释也不会覆盖本人对自己状态的描述。

研究依据与已有工作的区别见[中文项目稿](../01-研究计划/Research-Project.zh-CN.md)和[主张与证据矩阵](../07-文献与证据/主张与证据矩阵.md)。

## 2. 成功的含义

**研究成功**是形成可辩护的问题、与目标参与者共同设计的原型、透明的比较结果和可复现材料。负结果、用户不需要某类提示或低成本基线表现更好，都可以形成有效研究结论。

**产品成功**是用户可在明确授权下完成一次沟通任务：进入会话、获取可读字幕、辨识有限范围的发言人、控制辅助、处理断线与错误、结束并清理会话。它依赖真实设备与真实入口验证。

**自我觉察扩展成功**是本人认为支持及时、可理解、可拒绝且有帮助。不能把更低心率、更少小动作、更多服从提示或系统更高“情绪识别率”单独当作成功。

## 3. 用户与情境

| 层次 | 用户 / 情境 | 研究边界 |
|---|---|---|
| 首年核心 | 选择使用实时字幕的成年聋人及重听者；2–3 人、私密室内、低移动对话 | 招募前与相关社群共同确认价值；不替代手语、助听设备或个人沟通偏好 |
| 自我觉察探索 | 自愿选择一个或两个本人相关动作模式的成年人 | 可与核心参与者有重合，但单独同意、单独分析，不假设 DHH 身份意味着情绪困难 |
| 后续人群 | 第二语言使用者、年长使用者、希望减少社交信息负担的人群、明确提出需要的神经多样性使用者 | 每组重新开展需求工作；不从一组推断另一组效果 |
| 后续场景 | 双向口译、阅读 / 旅行视觉翻译、经同意的日常个人使用 | 新语言、移动、公众环境和长期使用分别验证 |

## 4. 三层交付

### A. 第一学年研究核心

1. 共创字幕和提示的边界、词汇、位置、可控方式。
2. 在同一稳定字幕层上实现匿名发言人标识与少量补充线索。
3. 比较字幕基线、全部符合条件的补充线索、经不确定性与显示负担过滤的补充线索。
4. 报告理解、误用、注意分配、可控感和失败恢复，而非只报模型准确率。
5. 交付可运行研究原型、实验材料、分析脚本和局限说明。

### B. 主项目产品路线

逐步接入真实眼镜与手表，形成会话管理、平台能力协商、原始数据最小化、跨设备同步、模型切换和功能降级。随后扩展翻译、OCR 和多设备输出。产品进展不自动构成用户研究有效性证据。

### C. 可选生理与微动作研究

在合法可用的信号接口和研究资源确认后，评估 HR / 可用 HRV + 活动 / 上下文 + 个人动作模式是否比手动请求或较简单的生理基线更有用。该分支可以延期或给出“不值得加入”的结论，不阻塞 A。

## 5. 核心功能与明确边界

| 核心能力 | 首版定义 | 不从该能力推导的结论 |
|---|---|---|
| 自适应字幕 | 可调字号、稳定行数、尾部增量修订、用户控制、有限空间布局 | 不等于眼动追踪或世界锁定 AR |
| 发言人关联 | 会话内 A/B/C；证据不足显示未知或重叠 | 不建立跨会话身份识别档案 |
| 社交辅助 | 可观察声学变化及少量待验证的沟通行为假设 | 不声称识别真实内心、欺骗、好感或人格 |
| 本人状态觉察 | 个人基线变化、活动背景与自述相互参照 | 不把 HR / EMG 当作情绪真值或诊断 |
| Jev 集成 | 结构化候选和允许动作建议，经过独立控制器 | 不以 API confidence 代表现实正确概率 |
| 日常模式 | 手动开启的腕部 / 手机支持，不必持续采集外部音视频 | 不默认全天候后台可用或全天续航 |

## 6. 暂定参数与冻结机制

以下是便于原型讨论的**起始配置**，须经平台核验、共同设计和试点调整，正式实验前生成版本化配置。

| 参数 | 初始提案 | 冻结前验证 |
|---|---|---|
| 活跃对话人数 | 2–3 人 | 重叠讲话与未知发言人的恢复 |
| 主要语言 | 一种招募语言，具体由招募资源决定 | 字体、识别、材料和参与者语言偏好 |
| 原始会话工作缓存 | 内存中的连续滚动窗口，最长 90 秒；不需要的模态不开启 | 内存、可删除性、能耗与实际回溯需要；允许进一步缩短 |
| 补充线索 | 同时最多一个活动提示槽；字幕始终优先 | 可读性与遮挡；记录任何界面变更 |
| 日常支持 | 默认关闭，参与者自行开启；暂定至多 1 次 / 10 分钟且 3 次 / 小时 | 自评负担、漏报与误触；手动请求单独记账 |
| 生理上下文窗口 | 30–120 秒仅为候选范围 | 信号更新、运动伪影、时间同步与对齐误差 |
| 新鲜度阈值 | 按实测采样 / 发布 / 送达间隔分别设定 | 不使用统一“实时”标签，不从旧读数即时推断 |
| 模型显示阈值 | 未设固定值 | 仅在独立校准材料上确定；无法校准则限制为观察性描述 |

长期数据保存期限必须采用承办机构批准的数据管理计划；90 秒是运行缓存设想，不是研究数据保存期限。
