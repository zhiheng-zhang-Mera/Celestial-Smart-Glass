## 2. 保留、调整和阶段

| 原始设计 | 本项目处理 | 落点 / 阶段 |
|---|---|---|
| 一个翻译核心、多个输入输出节点 | 保留单一语义版本与路由权威，避免眼镜与耳机各翻一遍 | 架构预留；双向口译为后续阶段 |
| 共享短期 Context Palace | 保留语言、最近话轮、临时发言人、实体、修订和输出状态 | 首版采用最小会话状态；不默认长期人物记忆 |
| 增量识别与 committed / speculative 区 | 字幕先实现稳定区与可修订尾部；音频队列晚些实现 | 字幕核心；TTS 后续 |
| 系统 TTS、耳返、AR overlay 来源隔离 | 保留来源标签和输出回执；任何模块不把自己的输出当外部新输入 | 统一契约和翻译扩展 |
| 视觉中心 / 眼动 + 停留触发 OCR | 保留交互目标；没有眼动 API 时明确为视野中心选择 | 后续视觉翻译，不用头向冒充眼动 |
| 文字旁注、Text Anchor、多帧融合 | 保留短命文字锚点和分层识别 | 后续功能；显示与空间锚定分别实测 |
| 观察 / 推断 / 不确定性分离 | 作为核心架构边界 | 社交线索与模型策略 |
| 高频轻量感知、低频深推理 | 保留增量状态和事件触发；频率由真实算力与数据更新决定 | 首版原则，后续性能实测 |
| 多人动态注意预算 | 首版限制为 2–3 人，只在证据允许时关联当前发言人 | 不基于未知关系推断谁“最重要” |
| 90 秒滚动缓存 | 保留为可缩短的工程上限提案；仅启动必要模态 | 不将原始构想的时长写成已优化参数 |
| 潜在意图或“读心”式辅助 | 将研究对象具体化为有证据的沟通线索与用户解释 | 无清晰真值的内心标签不进入首年主实验 |
| 相对个人变化 | 对外部人物仅维护必要的会话内基线；本人模块可自愿校准 | 不把基线偏移解释为特定情绪 |
| Store meaning, not footage | 保留最小化原则，同时承认语义摘要同样可能敏感 | 默认会话结束清理；保存需另行选择与约束 |

## 3. 新增内容

本轮新增研究问题、参与式设计、三条件实验、可替换 Jev 决策后端、消费级与研究级设备能力矩阵、Apple Watch / sEMG 可选模块、日常自我觉察、数据契约、开发里程碑与验收路径。新增模块不反向改变字幕和原始转写的事实层。

## 4. 对“完整项目”的解释

完整项目意味着长期设计、研究路径和工程依赖都有明确位置。首年先完成一个能独立回答问题的研究切片；后续功能保留输入输出、前置能力和验收标准，不用一份无限扩张的首年承诺替代工程排序。
