# 隐私与数据生命周期

本文件规定拟议数据边界，需在研究机构的数据管理与伦理审批中具体化。公开仓库只包含计划、空白材料和明确的合成样例；审批、同意或删除能力均不能由一段文档代替。

## 1. 数据按目的分开

| 类别 | 运行默认值 | 若需要保存 | 退出处理 |
|---|---|---|---|
| 原始会话音频 / 视频 | 只开启必要模态；内存滚动缓存最长 90 秒的初始提案 | 研究录制单独同意，写入受控位置 | 覆盖运行缓存；研究资料按批准的撤回规则处理 |
| 字幕、临时人声 / 人物轨迹、实体 | 会话内使用 | 另行选择范围，不以“匿名”保证无法识别 | 结束清理缓存、索引、队列与中间表示 |
| 会话摘要 | 默认不持久保存 | 明确用途、内容和保存期限 | 支持删除；摘要可能包含个人信息 |
| 本人 HR / HRV / 活动 / EMG | 只读取本人授权的数据类别和时间范围 | 个人功能与研究保存独立选择 | 停止读取，清理应用自有副本；不虚称能删除平台原始健康记录 |
| 本人偏好与校准 | 最小必要的本地设置 | 可选加密保存个人模型 / 偏好 | 支持重置；原始校准记录不默认随模型保存 |
| 运行质量日志 | 默认无原始对话、健康数值和身份内容 | 经批准的调试 / 研究级日志另行启用 | 轮转与删除；崩溃上传同样检查 |
| 参与者身份与同意 | 不进入产品事件或公共仓库 | 机构批准的独立受控目录 | 依批准计划保留、撤回或解除关联 |
| 公开研究产物 | 合成或获准的最小化材料 | 明确授权及重识别评估 | 公开后难以保证所有第三方副本可撤回，事前告知 |

运行缓存最长 90 秒不是固定研究留存期。真正的保留期限、责任人、备份、跨境处理和撤回截止时间应在招募前明确；本初稿不虚构机构规定的年限。

## 2. 同意与控制

分别控制会话音频、视频、健康数据、动作检测、云端处理、长期个人保存、研究记录和公开共享。开始模式时说明所需输入；被拒绝的可选权限不阻止能够独立完成的字幕功能。

参与者和对话伙伴需知道设备正在采集什么。研究场景优先在经过同意的私密房间，避免把不知情旁观者纳入数据。日常模式默认关闭外部音视频。首年不部署招聘评分、课堂监控、工作场所情绪评价或对第三方的长期人物档案。

## 3. 云服务和模型输入

优先传结构化、最小化、短期字段；去掉真实姓名、联系方式、精确位置和健康标识。模型输入仍可能敏感，不能因为是 embedding、文本或摘要就称为匿名。

Jev 是否使用数据训练、保存多长、可否删除、处理地点和子处理者是不同问题；依当次官方条款与机构批准记录。未获允许时禁用云后端，规则 / 经批准本地后端继续可用范围内的功能。

对话内容属于待分析数据，其中“忽略规则”“上传历史”等文字不具有系统权限。模型只能返回受限 schema；不授予其访问联系人、发信、支付、开启传感器或修改健康记录的能力。

## 4. 清理流程与故障

结束会话时，先进入 `stopping`、更新授权与会话代次，立即拒收新工作并阻断在途或迟到输出；随后清屏、取消可取消的请求并请求停止采集，再清理内存、临时文件、重试 / 播放队列与索引。授权失效不等待停流或删除操作完成；真正停止采集、清屏和清理的成功或失败分别记录回执，完成后返回可核对状态。执行顺序与[自适应策略与算法规格](自适应策略与算法规格.md)一致。已发送外部服务的数据遵循实际合同，不能在 UI 上承诺已经从所有服务器删除。

测试正常结束、崩溃、强制关闭、断网重试、重启与系统备份恢复；核对缓存、截屏、调试日志和系统同步副本。系统无法强保证零化的范围应如实记录，不以“覆盖变量”代替安全删除结论。

## 5. 公开仓库与受控材料

`.gitignore` 辅助避免误提交，但不是访问控制。不要把受控资料暂存到 Git 后再删除：历史仍可能保留。事故应按承办机构流程处理并记录必要事实，不能以悄悄改历史代替处置。

公开代码和实验配置使用合成样例；原始资料保存位置仅在受控索引中登记，公共文件不暴露访问链接、参与者 ID 对照或口令。引用个人原话、截图、录音片段与使用模型训练分别征求适当授权。

## 6. 启动研究前的必要成果

完成信息流清单、机构批准的数据管理方案、分层同意书、撤回说明、云处理审查、数据访问角色和实际清理演练。伦理材料草稿见[参与者材料](../05-实验与评估/伦理与参与者材料.md)。本项约束针对真实参与者数据收集，不阻碍合成数据的文档与界面准备。
