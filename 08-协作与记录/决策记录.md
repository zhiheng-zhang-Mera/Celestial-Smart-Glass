# 决策记录与风险

版本：2026-10-22；以下均为本轮研究 / 工程初稿中的设计选择，供后续导师讨论、共同设计与实机证据修订。不表示研究方案已获正式批准。

## CSG-D01｜HCI 问题与首年范围

**选择：**聚焦小组对话中字幕、发言人和补充线索的呈现、控制与恢复，首批与愿意使用字幕的 DHH 成人共同设计。日常本人状态、翻译与视觉扩展有独立阶段。

**依据与取舍：**同一项目可保留长期愿景，同时让首年研究在设备或模型变化下仍可完成。论文贡献来自用户问题、设计和比较结果；单纯整合 ASR、Jev 和商用设备不自动构成新颖性。[研究依据](../07-文献与证据/参考文献.md)

**重访条件：**共同设计否定核心需求、招募无法落实、显示限制无法支持任务。调整任务或人群需要重新解释研究问题，不仅更换应用名称。

## CSG-D02｜商用设备优先，能力分级

**选择：**优先 Meta Ray-Ban Display + 手机；普通 Ray-Ban Meta 作为部分输入 / 音频节点；Watch 与研究 sEMG 分开。第一年不自制 PCB 或光学。

**取舍：**减少硬件开发负担，但接受 SDK 权限、后台、显示与分发限制。无屏设备不能承诺视野字幕，消费命令事件不能承诺原始 EMG。世界锁定、眼动和原始阵列数据保留 unknown，直到实际核实。

**重访条件：**必须的研究变量确实无法由现成设备测得，且已有明确科学问题、资源、比较价值与维护能力，再考虑定制采集硬件。

## CSG-D03｜观察、解释、呈现分层

**选择：**原始转写、声学事实、社交假设、本人状态候选及最终呈现各为不同类型。只在用户选择下输出有证据的低负担辅助。

**取舍：**允许弃权、未知和失败，减少“读心”式宣称的吸引力；换取可以标注、比较、纠正与控制的研究目标。不从外部表情或本人生理数值认定真实内心。

**重访条件：**新线索类型有用户需求、可靠参考标签和外部验证；增加时另行设定可接受错误与退出机制。

## CSG-D04｜Jev 可替换，控制器独立

**选择：**拟实现明确 schema 的 DecisionProvider，预留 disabled / rules / local-approved / jev-cloud；这些是计划接口，不是已接通后端。Jev 指 TypeSafe 的结构化判断组件，不是 V-JEPA，也不承担原始音视频感知。版本、许可、数据处理与置信语义单独核对。

**取舍：**维护一个薄适配边界，避免模型供应或商业条款成为研究唯一依赖。高 confidence 不能绕过同意、TTL、用户开关或字幕优先级。

**重访条件：**替换后端改变候选意义或概率定义时，重新验证校准与实验条件；不默默沿用旧结果。

## CSG-D05｜布局探索与策略比较分开

**选择：**共同设计 / 试点探索布局；主实验冻结同一 ASR trace、字幕层、发言人映射和适应规则。C0 仅字幕；C1 基础调度辅助与 C2 门控辅助共用有效性、容量、队列、时效和用户控制，C2 再加可选筛选，C1 不保证每条候选显示。个人初始设置共同，之后的关闭不自动重开。

**取舍：**主要准确率比较为 C2−C0；C2−C1 是关键次要比较。它们解释策略净效果，不单独证明空间布局或校准机制的作用。C2 可改变提示密度，密度匹配为后续实验；准确率的具体区间与多重性见 CSG-D10。

**重访条件：**如果空间布局成为唯一主要假设，则新建明确布局对照，重新规划材料、样本与主指标，不混到现有条件中。

## CSG-D06｜自我觉察扩展不预设小动作有害

**选择：**由本人选模式、解释意义、选择支持；HR / 活动 / EMG / 自述提供不同类型证据。识别动作、解释意义、判断支持有效性分别评估。

**取舍：**个体校准与自述有负担，但能避免把普通活动、手语或有帮助的 fidgeting 病理化。没有原始信号访问时，连续肌电研究不启动，核心字幕仍能继续。

**重访条件：**用户认为提示增加自我监控负担，或肌电没有增量价值，缩减为手动或简化生理版本。

## CSG-D07｜短期上下文和有限保存

**选择：**原始缓存最长 90 秒仅为初始上限提案，最小化模态与保留；会话结束默认清理。研究保存、长期个人概览、云处理独立授权。

**取舍：**减少长期建模机会，但避免人物档案和不必要外部数据成为默认产品。摘要及特征同样可能敏感，不能声称天然匿名。

**重访条件：**研究确需长窗口或长期校准时，先明确增量问题、数据治理和用户价值，再调整生命周期。

## CSG-D08｜本仓库可独立开展研究

**选择：**中文主导航与模块所有权在本仓库；未来代码和可执行契约随本产品构建。Celestial Book 提供设计 / 工作流参照，Throne 以后按实际需求提供可选能力。

**取舍：**避免博士研究等待主个人项目完成；跨仓只传递必要契约和固定引用，不复制任务状态或健康数据。

## CSG-D09｜回放几何与访问支持明确

**选择：**首年受控任务暂用 18 段 45–60 秒同框视频、36 题、三个材料组；每人每条件一组，不重复同一片段。屏幕播放对话，眼镜显示字幕和视野内标签；保留正常音视频和惯常助听方式，片段后在同一伴随界面作答。

**取舍：**冻结输入提高条件可比性，主要题考察跨话轮信息整合而非照抄提示；结果限于受控回放理解，真实对话参与由独立可行性扩展检验。六个恢复探针单列为正确候选、可恢复语义错误和合法抑制的逐例观察，不用于泛化安全率主张。

## CSG-D10｜估计目标与设计计算分层

**选择：**唯一主要估计 Δ20（C2−C0 标准化准确率差）报告双侧 95% 区间；次要准确率族 Δ21（C2−C1）和 Δ10（C1−C0）各报告 Bonferroni 97.5% 区间。体验、探针及可选支线描述性/探索性报告，不用未显著结果声称等效或安全。详见[统计预注册草案](../05-实验与评估/统计分析预注册草案.md)。

**证据与取舍：**N=24/36/48 合成[设计敏感性计算](../05-实验与评估/样本量与精度规划.md)已运行，保留交叉层级与分配结构；分析的是描述性配对差的重复抽样误差，未拟合最终 GLMM 或验证其功效与区间覆盖。约 24 人仍是暂定招募起点，最终目标和停止规则在主结果不可见时冻结，不按显著性追加样本。

## 风险与应对

| 风险 | 可观察信号 | 应对 / 停止条件 | 负责人角色 |
|---|---|---|---|
| 平台无法显示或无法合规测试 | 接口 / 权限失败、分发受限 | 换已支持设备，记录适用范围 | 平台开发 |
| 自动归属错误造成错误解释 | 错人 / 重叠错误、用户反馈 | 未知状态、减少自动关联、限制场景 | 感知与研究 |
| 线索没有增加理解 | C0 相同或更好、访谈负面 | 保留字幕和用户选择；发表真实结果 | 研究负责人 |
| 提示造成过多干扰 | 高频拒绝、占位、主动关闭 | 降密度、改时机或停用该类别 | 交互设计 |
| 本人信号受运动混杂 | 活动变化和传感异常一起发生 | 活动负例、质量拒绝、不做情绪命名 | 生理支路 |
| 原始 EMG 无法取得 | 只有离散命令 API | 控制路径保留，研究路径延期 | 平台开发 |
| 数据 / 模型泄漏 | 同人同会话跨切分、测试调阈值 | 先冻结切分；保留审计与独立测试 | 分析负责人 |
| 字幕或提示长延迟 | age / P95 上升、过期候选积压 | 有界队列、过期丢弃、简化后端 | 工程负责人 |
| 资源不足或范围膨胀 | 多个新模态阻塞核心实验 | 依据章程裁剪到最低研究版本 | 项目负责人 |
| SDK / 模型版本变化 | API 或行为发生漂移 | 固定版本、单独评估、偏离记录 | 发布维护 |

上述角色是责任分工建议，不代表已指定某位导师或团队成员承担。具体资源与人选在入学和合作确认后填写。
