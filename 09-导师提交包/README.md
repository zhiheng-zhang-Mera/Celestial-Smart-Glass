## 阅读顺序

1. [研究概要](研究概要.md)：快速判断研究问题、贡献、范围与资源需求。
2. [完整研究计划](完整研究计划.md)：包含中英文摘要、文献定位、理论逻辑、研究问题、技术方案、研究设计、统计方案、伦理、进度和博士延展。
3. [研究实施附件](研究实施附件.md)：实验执行、材料与问卷、分析规则、平台验证、数据字典和开发验收的操作文件。
4. [开题讨论与答辩准备](开题讨论与答辩准备.md)：针对新颖性、实验效度、设备依赖和可行性的问答。
5. [提交前确认事项](提交前确认事项.md)：明确需要与导师及承办机构落实的事项及其处理方案。

正式排版文件由上述内容生成。主计划用于完整阅读，实施附件用于审查可执行性；两者不要求读者先访问仓库。[构建说明](构建/README.md)保存生成方法和最终目录页码，[图示说明](图示/README.md)说明架构图及实验布局图的用途。

## 适用范围

这是一份拟议研究的完整方案，不是已批准的机构开题表，也不包含虚构实验结果。研究协议状态为 `PROPOSED`。文献核对、设计文件和设计阶段计算，与原型实现、实机验证、伦理审批和参与者研究分别记录。提交包使用中文导航，英文申请稿与中文范围保持同步。

与仓库长期维护的对应关系：研究论证在 [01 研究计划](../01-研究计划/README.md) 与 [07 文献与证据](../07-文献与证据/README.md)，操作细节在 [03 系统架构](../03-系统架构/README.md)、[05 实验与评估](../05-实验与评估/README.md) 和 [06 开发计划](../06-开发计划/README.md)。正式稿修订时应同步受影响的研究条件、参数和任务，不建立另一套相互冲突的承诺。
