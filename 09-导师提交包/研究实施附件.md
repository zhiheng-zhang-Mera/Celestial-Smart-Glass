# 智能眼镜自适应沟通辅助研究：实施附件

申请人：Zhiheng Zhang

版本：CSG-PROPOSAL-20261022-v2

日期：2026-10-22

本附件供与李雪亮博士讨论实施方案，可独立阅读。研究为 PROPOSED，原型为 PLANNED，实机及参与者研究为 NOT_RUN。仅第 6 节合成设计计算已经运行，不代表伦理批准、产品有效或样本量充足。

## 1. 研究对象、招募与执行流程

### 1.1 入组与研究关系

核心研究面向年满 18 岁、自我认同为聋人或重听者（DHH）、愿意在口语任务中使用书面字幕的成人。先确定主要研究语言和沟通支持。默认不要求听力图、诊断或健康史，不以熟悉人工智能为资格。设计关注字幕经验、偏好和伙伴关系，不只追求转写指标 [HCI-02, HCI-11]。

经机构批准的社区或公开渠道招募。私密筛选询问年龄、字幕意愿、语言、沟通支持、佩戴调整、休息及材料暴露。联系方式与答案分开；不按能力挑选实验顺序，不利用师生或雇佣关系施压，不在公开仓库收集报名和健康资料。

说明用语：“我们想知道额外提示何时帮助、何时打扰。你可以只用字幕或拒绝提示。设备会出错，这不是社交能力评判或医疗工具。”合理调整仍不能满足的需要记为设计限制，不归咎于参与者。

### 1.2 阶段与人数

| 阶段 | 规划参与及活动 | 进入下一阶段的证据 |
| --- | --- | --- |
| 技术与伦理准备 | 使用合成或获准材料，不采集未批准研究数据 | 合法平台路线、可访问说明、数据和停止流程 |
| 形成性共创 | 6–8 名 DHH 成人；情境访谈与 2–3 种低保真布局 | 词表、布局、未知状态、退出方式和分歧记录 |
| 试运行 | 4–6 人，检查材料、负担、测量与日志 | 修订理由、精度规划和主研究冻结版本 |
| 主研究 | 暂定随机分配 24 人；被试内比较三条件 | 按冻结计划执行、报告缺失与偏离 |
| 可选现场扩展 | 主研究中 6–8 人及另行同意的伙伴 | 真实输入、舒适度、隐私与设备验证通过 |

24 是随机分配目标，不事后补足完整或高表现完成者；36、48 人仅用于资源与精度讨论。试点参与者不纳入正式主实验分析。共创者若再参加，须预先明确资格、材料暴露和记录方式。HR／EMG 探索独立立项。

### 1.3 单次主研究流程

| 环节 | 时间起点 | 实际执行规则 |
| --- | --- | --- |
| 说明、同意、佩戴与练习 | 约 15 分钟 | 确认理解、停止入口和通常沟通支持；练习不计分 |
| 三个条件区块 | 每区块约 12–15 分钟 | 各六段对话、每段两题，区块末填写六项体验题 |
| 区块间休息 | 两次各至少约 5 分钟 | 可增加，不因延长休息记为错误 |
| 六探针、访谈及结束说明 | 约 10–15 分钟 | 与主要任务分开，先处理不适，再进行自愿讨论 |

先按 80–90 分钟预约，待试运行校准，不强制限时。可拆两场，保留顺序、暴露和间隔记录，另计出行及沟通支持。共创、试运行各按 75–90 分钟，现场扩展另按 45–60 分钟。

同意、访问支持和练习完成后，首段主要材料前随机分配。允许暂停、仅字幕、跳题及退出；关闭不静默重开。切换条件需恢复设置时由本人明确操作。采集前冻结材料、答案、候选池、策略、分配、分析及停止规则；公开草案不等于预注册。

## 2. 十八段材料、条件分配与完整评分示例

### 2.1 材料规模与题型

制作 18 段 45–60 秒的两至三人低风险对话，每段两题，共 36 题。A、B、C 三集合各六段、12 题，各含三段两人和三段三人对话。T1 检查强调与对比后的事实整合，T2 检查明确沟通功能与下一步，T3 检查重叠或修正后的最终版本；每集合每类题各四道。

| 槽位（各集合对应） | 人数与题型 | 低风险制作主题 |
| --- | --- | --- |
| A01／B01／C01 | 两人；T1＋T2 | 展板、读书会或工作坊的时间地点 |
| A02／B02／C02 | 三人；T1＋T3 | 物品清单、存放位置及修订 |
| A03／B03／C03 | 两人；T2＋T3 | 设备借用与尚待确认事项 |
| A04／B04／C04 | 三人；T1＋T2 | 活动角色与行动顺序 |
| A05／B05／C05 | 两人；T1＋T3 | 文件版本与发送对象 |
| A06／B06／C06 | 三人；T2＋T3 | 流程、地点变更和最终安排 |

每题整合至少两个话轮，答案依据完整录音、脚本与独立标注，不反推模型输出。集合匹配长度、事实数、题型和输入难度，不重复故事答案。能抄提示作答的题重写；实质歧义题移出主要题集。

至少两名标注者不看模型判断，独立给答案和理由后讨论分歧。材料卡存题号、对话号、集合、题型、相关话轮、答案、干扰项理由及许可。试点按 C0 可答性、地板／天花板和负担修改，不挑 C2−C0 最大的题；4–6 人不足以稳定估计单题难度。

### 2.2 三条件及六行平衡块

C0 仅字幕。C1 为基础调度辅助：在共同有效性、容量与调度约束下呈现候选，不增加选择性不确定性或显示负担过滤。C2 在同一候选池上增加冻结的选择性策略。共同规则包括单槽容量、队列、冲突、替换、去重、TTL、未知归属、用户关闭和设备错误；C1 不承诺所有候选都实际可见，也不作为故意拥挤的弱对照。

每人看三个不同集合，同一段不重复。六行基本分配如下；执行程序先重复所需块数，再按固定种子打乱分配槽位。

| 基本行 | 三时期的条件顺序 | 对应材料集合顺序 |
| --- | --- | --- |
| 1 | C0 → C1 → C2 | A → B → C |
| 2 | C1 → C2 → C0 | C → A → B |
| 3 | C2 → C0 → C1 | B → C → A |
| 4 | C0 → C2 → C1 | A → C → B |
| 5 | C1 → C0 → C2 | C → B → A |
| 6 | C2 → C1 → C0 | B → A → C |

重复四块得到 24 人：六种条件顺序各四人，条件×集合及集合×时期组合各八人。这是二因素边际平衡，不是条件×时期×集合完整三因素交叉。集合内顺序预先打散，同段两题成组。36／48 人对应六／八块，不自动扩大授权。planned 编号为空槽；参与者无法完全遮蔽，评分清理可先用中性代码。

### 2.3 呈现与字幕控制

前方单屏同框播放两至三名发言人，眼镜使用屏幕相对字幕和匿名角色标识，不是现实人物的世界锁定字幕。坐距、画面、字号位置和个人初始设置试点后固定。保留通常沟通支持，音量舒适且跨条件一致。段末在伴随界面作答，可代录回读，不覆盖播放中的字幕。

录制后用同一 ASR 版本生成增量 trace。三条件共享文本、修订、时间、映射及基础故障，人工参考仅作核查。关键事实严重缺失时，采集前统一重录、重跑或替换整段并记原因；非关键错误可登记保留。结论限于可用字幕基础上的受控回放，不外推任意噪声环境 [HCI-01, HCI-12]。

### 2.4 完整链示例：工作坊准备

以下为拟录约 58 秒的合成示例，不是已经录制、运行 ASR 或测得性能的材料。目标时间须经自然试读校准。声音标记只供导演和标注，不自动成为给参与者看的解释。

| 目标时间 | 发言人与完整脚本 | 可核查事实 |
| --- | --- | --- |
| 0–7 秒 | 甲：我把工作坊安排写成周四下午、大会议室。你们看过这张旧表吗？ | 引出旧版本 |
| 7–14 秒 | 乙：看过。要改的是日期，改到周五下午；房间按昨晚确认的那一间。 | “周五下午”重读；新房间需下一话轮 |
| 14–20 秒 | 丙：我查过，昨晚定的二楼小会议室可以用。我周五上午先把桌牌送过去，可以吗？ | 明确房间并请求确认 |
| 20–27 秒 | 甲：上午送可以。材料分工呢？我能带纸张，但是胶带昨天没买到。 | 接受送物安排，说明分工缺口 |
| 27–34 秒 | 乙：胶带我来带。投影仪还没有借到，我需要问一下管理员。 | 投影仪仍待确认 |
| 31–34 秒，与乙重叠 | 丙：那要不要取消投影？ | 发生重叠，不证明争执 |
| 34–41 秒 | 乙：这件事的结果，我会在午饭前发给你们。到时候请留意小组消息。 | 对象须结合前文；承诺不等于已借到 |
| 41–49 秒 | 甲：好。我带纸张，丙送桌牌，乙带胶带并确认投影仪。我按这个分工准备。 | 汇总分工 |
| 49–58 秒 | 丙：我按新的活动时间和刚确认的房间准备。投影仪有结果再告诉我。乙：对，借不到我们再一起改展示方式。 | 不在总结句重复整组答案 |

为解释自然错误处理，可在示意 trace 中假设两次“桌牌”均显示为“桌排”，其他文字不变；三条件同样保留，人工参考仍写桌牌。正式实验必须用实际识别输出替换这一拟制 trace，不能把它当成 ASR 性能样本。

| 同一固定候选与证据 | C0／C1 的处理 | C2 的示例处理 |
| --- | --- | --- |
| E1：乙 7–14 秒重读；标签“强调” | C0 不显示；C1 在共同调度允许后显示 | 通过冻结判据、显示预算允许时显示 |
| E2：丙 14–20 秒；候选“可能在请求确认”，任务分数未达额外判据 | C0 不显示；C1 未触发硬无效规则时按基础调度显示 | 因不确定性弃权，不能改写成“没有请求” |
| E3：31–34 秒重叠；标签“重叠发言” | C0 不显示；C1 按共同调度显示 | 若字幕占用／更新代理达到额外门槛，抑制或在原有效期内延后 |

本示例假设自愿开启辅助且三事件不竞争同一槽位，不附虚构正确概率。正式候选池须冻结每个决定和时间，不能保留示例中的“若”。额外分数门槛与共同硬有效性不是同一回事。

| 主要题 | 反应选项 | 答案与评分 |
| --- | --- | --- |
| Q1：大家目前应按哪一组活动时间和地点准备？ | A 周四下午、二楼小会议室；B 周五下午、二楼小会议室；C 周五下午、大会议室；另有不知道／跳过 | B=1；A、C、不知道=0；跳过=缺失。乙给日期、丙给房间，单看一维仍有两个选项 |
| Q2：关于尚待确认的事，应按哪组对象与反馈时间理解乙的承诺？ | A 乙确认投影仪能否借到，今天下班前反馈；B 乙确认胶带是否备好，午饭前反馈；C 乙确认投影仪能否借到，午饭前反馈；另有不知道／跳过 | C=1；A、B、不知道=0；跳过=缺失。结合未借到与“这件事”的时间承诺，单看一维仍有两个选项 |

实质选项位置预先打散平衡，同题跨条件相同。组合题整体评分，不事后加部分分。主任务不逐题反馈；反应时仅探索、暂停另记。约 60 秒提供继续、跳过或休息，不自动判错。重播按统一访问规则，不依据答案决定。

## 3. 六个恢复探针与曝光记录

主要任务后安排六个独立片段：两个正确候选、两个可恢复的低风险语义错误、两个合法抑制。每类有两个不同且尽量匹配长度、复杂度的版本，分别分配到 C1／C2，并跨参与者交换。每人每种策略分配三例，但不要求实际看到三次提示。

| 探针类别 | 具体操作 | 观察与限制 |
| --- | --- | --- |
| R1、R2：正确候选 | 完整脚本支持的低风险线索，保留正常调度 | 如何结合字幕、核对或忽略；不预设必须采纳 |
| R3、R4：可恢复语义错误 | 在独立研究场景设置与对话不符的有限解释，但格式、归属与时效有效 | 是否自主发现、依据何在、如何恢复；不涉及健康、金钱或人格 |
| R5、R6：合法抑制 | 一个候选已过期，一个归属不明，按共同规则不显示或不附着 | 如何理解缺失／未知；不能关闭 TTL 或猜人制造曝光 |

分配示例为：一组将 R1、R3、R5 分给 C1，其匹配版本分给 C2；另一组交换，并平衡两个策略先后。正式片段和顺序试点后冻结。R5 的过期与 R6 的归属不明是不同硬规则，须分别描述，不把这对当作同一机制的重复样本。

C2 可以合法抑制正确或错误候选；不为了“可比曝光”放松保护。逐例记录候选生成、提交、真实回执层级、是否报告注意到、回答与恢复动作。回放后问“你依据哪些信息理解？”“想核对、继续、关闭，还是无法判断？”研究者提示后才指出错误，不计作自主发现。

报告分配、实际呈现及报告注意到的例数，附逐例恢复叙述。六例不足以估计自然识错率、假警报率或因果安全收益；曝光后比较受门控选择影响。结束时解释全部安排，强调不是能力考试。纠正、拒绝和理解边界是设计目标，不等于服从模型 [HCI-08]。

## 4. 问卷、访谈、同意与数据字段

### 4.1 六项体验题及结束选择

每条件后使用以下六项自编单项题，1 为“完全不同意”，7 为“完全同意”，另设“不适用／不愿回答”。它们没有被验证为统一量表，不求和形成可用性、信任或心理健康总分。

| 编号 | 完整条目 | 分析边界 |
| --- | --- | --- |
| E1 | 为跟上这组对话，我需要付出很多努力。 | 高分表示更费力，不反向包装 |
| E2 | 我因界面中的额外信息而错过了后续字幕。 | C0 可不适用，不填 0 伪造对称 |
| E3 | 这组任务中，我感到眼部或视觉不适。 | 与实际不适和停止事件对照 |
| E4 | 我知道怎样暂停或关闭不需要的辅助。 | 控制方式是否可理解 |
| E5 | 我能决定是否采纳系统提供的提示。 | 无提示时可不适用，主体性不等于服从 |
| E6 | 当系统没有给提示时，我知道这不一定表示没有相关信息。 | 对弃权的理解，不替代实际能力检查 |

各题报告分布、中位数、配对摘要及缺失／不适用数；有足够数据才探索有序混合模型。不适先处理。结束选择 C0、C1、C2、取决于情境、都不想用或无法判断，追问希望保留及必须改变什么。偏好不代替准确率。

### 4.2 访谈与设计解释

共创讨论字幕问题、未知说话人、不应出现的线索、关闭与伙伴知情。主研究请本人选两三个事件，再问：提示意味着什么；依据哪些信息；是否改变理解；能否自由忽略；缺失时怎样判断；出错后怎样恢复；何时更愿意仅用字幕。

不诱导认同系统。区分本人叙述、研究者解释和建议，保留负例；伙伴意见单独分析，不覆盖佩戴者意愿。冻结时明确反思性或代码本主题分析，不混用质量标准。贡献来自设计演变与可转移理由，不只是做出界面 [METHOD-02, METHOD-03]。

### 4.3 分项同意、停止与撤回

核心同意说明研究限制、答案与最小日志、暂停退出、补偿、本地／云处理方及保存方式。录音、视频、引语、可识别公开演示、现场扩展、再次联系和 HR／EMG 分别同意。拒绝可选记录不自动排除其他活动；必要限制逐项解释。

不适、隐私担忧或沟通支持丢失时立即暂停，询问休息、调整或结束。未同意旁人被录入时停止采集并隔离处理。退出需确认范围、停止新工作、记录请求、说明可定位资料、执行获准删除并结算补偿；不按正确率奖励。

招募前填清机构、审批、联系方式、保存期限及起点、撤回期限、备份到期和责任人，不编造保存年数。不可逆匿名化或汇总可能无法定位个人，公开副本可能被复制，须事先说明；默认不公开可识别声像和精细时间线。

### 4.4 最小数据清单

| 数据组 | 核心字段 | 保存与解释约束 |
| --- | --- | --- |
| 分配和版本 | 研究编号、条件、时期、材料集合／哈希、版本、顺序、偏离 | 身份映射另存；planned 槽位不当真人 |
| 主要作答 | item_id、clip_id、题型、选项、正确值、确认时间、暂停、缺失原因 | 不知道记 0；拒答／跳过／未呈现分开 |

## 5. 主要统计模型、区间与缺失规则

### 5.1 估计目标与分析集

唯一主要对比为 C2−C0 的平均正确概率差 Δ20，以百分点表示。对时期、材料集合和题型各三水平等权标准化，目标包括用户关闭、合法弃权和现实降级，不只分析看到或相信提示的人。次要准确率对比为 Δ21 和 Δ10。24 人×36 题约 864 条作答不是 864 名独立参与者。

主要分析纳入合格、同意有效且有至少一条可评分作答的已随机分配者，不按低分、经验、关闭或未完成排除。资格错误及重复参加按批准流程处理。任务未呈现记技术缺失；任务已呈现时，模型超时、提示未显示或关闭不排除答案。按事件 ID 和确认时间去重，不挑正确版本。

### 5.2 拟议 GLMM 与边际标准化

采用二项 logit GLMM，C1、C2 为数值 0／1 指示变量，C0 为参考；M0 公式为：

```r
correct ~ C1 + C2 + factor(period) + factor(material_set) + factor(item_type) +
  (1 + C1 + C2 || participant_id) +
  (1 + C1 + C2 || item_id) +
  (1 | clip_id) + (1 | participant_id:clip_id)
```

参与者和题目的条件斜率允许反应异质性；对话与参与者×对话截距处理同段两题相关。随机效应相关预先固定为零。拟用 lme4::glmer、binomial(logit)、nAGQ=1 的 Laplace 近似、bobyqa、maxfun=200000，记录版本与所有警告。这是待实现的分析规范，不是本轮已经拟合的模型 [METHOD-04]。

每个条件在 27 个时期×集合×题型格计算固定预测，再对该条件的参与者、题目、对话及人×对话随机效应分布积分；斜率使积分方差随条件变化。等权平均得到 μ0、μ1、μ2，再求差。用固定 Gauss–Hermite 节点或经验证的等价积分，不以随机效应设零的 logistic 代替总体平均。固定优势比不是边际风险差。

六行设计没有完整三因素交叉；27 格标准化依赖加性固定效应和所定随机结构，包含未完整交叉单元的模型预测，不保证已识别条件×时期／题型交互。交互只能预先另定或标为敏感性探索。

### 5.3 区间、重复拟合及降级

Δ20 报告双侧 95% 参数 bootstrap 百分位区间；次要准确率族 Δ21、Δ10 各用 97.5% 区间，按 Bonferroni 控制该族。体验、探针、分层与现场结果仅描述或探索。跨零不等于等效、不劣或安全；未论证界值不作非劣效结论。

固定种子并固定 2000 次 bootstrap 尝试，每次重新生成随机效应和二元响应，语义对应 parametric、use.u=FALSE；不能固定原随机效应只重抽作答。固定模型稳定时可用 bootMer；需要降级时显式编写 simulate 加同一拟合／诊断包装器，bootMer 不会自动换模型。每次用相同标准化函数计算 μ 和 Δ [METHOD-04]。

记录失败、警告、边界方差及成功数，不删失败后补足 2000。有效重复少于 1900 则未通过计算检查，不给确认性区间结论；仍需报告失败选择影响及端点 Monte Carlo 不稳定性，另行验证覆盖与失败率。

| 顺序 | 预先规定的处理 | 何时降低结论强度 |
| --- | --- | --- |
| M0 检查与复核 | 查编码、矩阵、分离、梯度和 Hessian；不改模型收紧容差，以 nloptwrap 复核 | 不按效应方向或显著性选择优化器 |
| 边界与奇异性 | 稳定边界解可保留并报告，不自动删随机斜率 | 数值失败与零方差分别判断 |
| M1、M2 | M0 仍不可估先移除参与者×对话截距；仍失败再同时移除两类 C1 斜率，保留 C2 斜率 | 记录每步原因及 bootstrap 中结构比例 |
| 仍不能可靠拟合 | 报告描述配对差异，按参与者及对话交叉重抽样作探索；两题成组、集合分层 | 不把需删除主要 C2 异质性的截距模型冒充原确认性分析 |

奇异性、优化成功与有效推断不同；官方文档不为本项目样本量背书 [METHOD-04]。不得按 AIC、效果或有利方向挑选降级路线。

### 5.4 缺失与其他结果

主模型使用可评分作答，依赖给定变量及随机结构后缺失可忽略的假设，不能由数据自动证明。按条件、时期和集合报告分配、呈现、作答及缺失原因。不知道是有效作答 0；跳过、拒答、退出、日志丢失与未呈现分开。

缺失敏感性至少包含四项：第一，非技术未回答的 Δ20 低界情景把 C2 缺失设错、C0 设对，高界反之，并附各条件全错／全对；所有条件同时全错不是差值最坏界限。第二，在每条件至少 8／12 题可评分者中重复估计，仅作完整度敏感性。第三，按退出、关闭与设备故障描述暴露。第四，模式混合假设将缺失作答 log-odds 相对可观测作答下移或上移 0.5、1.0，检查结论改变；这些参数不是从不可观测数据中识别的事实。

答案错误由不知条件和主结果者统一审查；事后重评分保留原版及敏感性版。负担相关缺失、模型不稳或敏感性改变结论时降为探索性。整体比较不能分离校准、负担适应与提示密度的作用。

## 6. 已运行的设计精度模拟

### 6.1 实际执行与生成假设

合成计算已完成 11 个假设×3 种人数，每组合 4000 次，共 132000 次；主种子为 20261022。环境为 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。源码与测试 SHA-256 匹配 manifest；8 项单元检查通过，覆盖平衡分配、边界输入、积分独立核对、概率校准、可复现性、解析方差及零效应中心。没有真实参与者观察。

生成器保留六行分配、18 段／36 题，并加入独立正态的参与者、题目、对话、参与者×对话截距，以及参与者和题目的条件斜率。每次重新抽取人和材料效应，不只对固定题目条件化。异质性假设如下，数值为 log-odds 标准差，不是先导或文献测得的参数。

| 假设 | 四种截距：参与者／题目／对话／人×对话 | 条件斜率：参与者／题目 |
| --- | --- | --- |
| 低 | 0.40／0.35／0.15／0.10 | 0.15／0.10 |
| 中 | 0.75／0.60／0.25／0.20 | 0.35／0.25 |
| 高 | 1.00／0.80／0.40／0.35 | 0.60／0.45 |

时期与集合固定效应各取 −0.10、0、+0.10，以 60 点 Gauss–Hermite 积分和求根校准总体正确率。生成器在九个时期×集合组合积分，题型效应未另设；正式分析则按第 5 节包含题型、使用 27 格。C1 设为 C2 平均提升的一半，只是模拟设定，不是预期证据。

估计器是每人 C2−C0 可观察正确率差的等权平均；任一条件全缺失则不能贡献配对差。它不等同 GLMM 边际估计器；部分交叉与 logit 非线性可带来少量设计偏差，已计入误差汇总。本计算没有拟合 GLMM 或验证功效、区间覆盖。

## 7. 非阻塞算法、数据契约与原始权限

### 7.1 决策边界

观察、候选和呈现三层分离。字幕管线独占原文及修订，模型不得改写原文来支持解释。候选含标签、证据 ID、源版本、观察／推断类型与有效期。后端仅建议 show、defer、abstain、no_op，确定性控制器决定呈现。

会话为 inactive、preparing、active、stopping，字幕可用性与辅助开关分离。停止／撤回先更新授权与代次，再拒收、清屏、取消请求和停源；异步返回重新核验，旧代次不得重开。模型不阻塞字幕与停止通道；断流仍按本地 deadline 清除过期提示。

共同硬门控包括关闭、用途不符、格式错误、未知标签、缺证据、源修订、过期、时钟不明、猜人附着、遮挡字幕及终端不可用，高分不能抵消。show 不证明看见；defer 不延长 TTL；abstain 终止当前版本；no_op 不保留失效内容。

### 7.3 契约、Jev 与可替换后端

事件含 schema、事件／会话／流 ID、源类型、观察／发布／接收时间、时钟域误差、窗口、有效期、版本、用途及质量／缺失。年龄为“当前协调时钟减映射后的源 window_end”，不用接收时间刷新；未知或异常未来时间不截零。OutputReceipt 分开提交、设备接受、绘制及物理呈现，无证据写 unknown。

### 9.2 资源和预算公式

先盘点一套显示设备、兼容手机、现有计算机、获准材料、场地、沟通支持、标注和安全存储；备用优先借用，不默认新增 GPU、Watch 或 Aria。采购核对研究必要性、接口、许可、替代、报价和责任，不重复要求已有授权。

共创 6–8 人及试点 4–6 人各按 75–90 分钟，24 人主研究按 80–90 分钟，直接接触合计 44.5–57 人时；主研究改 36／48 人分别为 60.5–75／76.5–93 人时。复核、伙伴、交通、拆场和沟通服务最低预约时间另计，不能把接触小时当完整劳动或费用。

总预算按设备、访问支持、参与者补偿、标注、计算、数据管理、运行与批准准备金求和；核心、Watch 和 EMG 分支分别列账。标注工时按“培训＋源材料小时×主标和需双标的人时系数＋分歧复核”；API 按开发批次、候选触发次数、输入／输出计费单位及有限重试计算；存储按实测字节量、获准副本与保留期计算，避免重复计费。

库存、补偿标准、服务费率和报价待落实，不编人民币总价。待报价不记零元，批准上限不是市场估价。可选模型和传感器不挤占补偿与沟通支持；云费用触顶停止可选调用，不自动续费。
