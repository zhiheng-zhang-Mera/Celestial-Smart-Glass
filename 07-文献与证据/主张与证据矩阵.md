# 主张与证据矩阵

**状态：2026-10-22 的研究论证与核验清单。** 本仓库首先是一套研究及开发文档；以下“可支持”指文献或官方资料允许的表述，不表示本项目已经实现、校准或验证。全部键值与 URL 见[参考文献](./参考文献.md)。

## 1. 证据等级与措辞

| 类型 | 可以怎么使用 | 不能怎么使用 |
| --- | --- | --- |
| 原始用户研究 | 描述特定人群、任务和测量下的结果 | 直接转写为本项目效果或所有人群的规律 |
| 探索性质性／研究型设计 | 支持需求、体验、解释与设计问题 | 宣称因果疗效、普遍准确率或总体代表性 |
| 技术原始研究 | 支持论文限定任务中的可实现性 | 推导消费硬件权限或未测试的自然行为能力 |
| 综述／方法框架 | 提供概念边界和研究设计依据 | 冒充新开展的实验验证 |
| 官方接口／厂商研究 | 判断文档所述能力、版本及限制 | 把宣传、内部工具或研究权限当作本地已可用能力 |
| 本项目候选主张 | 作为可检验假设与待办项 | 写成已经达成的指标或结论 |

主准确率题目只使用预先约定、低歧义参考答案。脚本作者意图、独立标注一致性与参与者解释分开保存；不以对他人真实情绪的推测构造“金标准”。

## 3. 设备、模型与数据链路

| ID | 主张／问题 | 证据 | 可以确认的范围 | 不得承诺／待验证 |
| --- | --- | --- | --- | --- |
| T-01 | Meta Ray-Ban Display 是候选显示终端 | META-01、META-03 | 存在带显示产品及兼容显示的开发方向 | 不是所有 Ray-Ban Meta 都有显示；本项目尚未实机跑通 |
| T-02 | DAT 可用于所需输入和实时呈现 | META-02 | 文档区分稳定与实验性功能及发布边界 | 必须核验型号、SDK、固件、权限、开发模式和发布资格 |
| T-03 | Neural Band 能提供原始 sEMG | META-03 描述消费事件路径；META-04/05 描述另一路研究接入 | 研究接口存在 EMG/IMU 流；消费产品可产生控制事件 | 不能把 click/gesture 事件当作肌电，不能把研究批准视为默认权限 |
| T-04 | 高精度细微手势解码意味着能识别全部日常动作 | EMG-01 是特定计算机输入任务 | sEMG 可支持精细运动解码研究 | 自发动作、姿势变化、未知行为和跨日漂移须独立测试 |
| T-05 | Apple Watch 高频心率可直接驱动实时眼镜提醒 | APPLE-01、APPLE-02、APPLE-03 | 测量、写入、传输是不同层；可设计手机桥接 | 实机验证数据年龄、后台运行、丢包、时钟、缺失、耗电；不承诺端到端 SLA |
| T-06 | 每几秒的 BPM 可以算出 HRV | APPLE-04 | HRV 需要适当的逐搏间期／原生 HRV 数据 | 稀疏 BPM 不够；不能把插值后的 BPM 叫作真实 RR 间期 |
| T-07 | Jev 是原始多模态感知器或 V-JEPA | JEV-01、JEV-03 | 核心支持文本与结构化状态；图像为实验功能 | 不是 V-JEPA；首年不依赖原始音视频或实验图像链 |
| T-08 | Jev confidence 直接等于正确概率 | JEV-02 | 是模型输出分布的统计摘要 | 必须用独立标注、任务内可靠性与选择性风险评估，不能只显示模型分数 |
| T-09 | Jev 不训练客户数据，所以没有保留或隐私风险 | JEV-04 | 厂商声明不用于训练 | 处理协议、遥测、保留、地区与批准流程必须另核实 |
| T-10 | 屏幕方向提示等于 3D 空间锚定／眼动注意力 | 当前仅为保守界面方案 | 可先实现屏幕相对区域与已验证来源方向 | 不假设 6DoF 世界锚定、原始多通道麦克风或眼动；头向不是注视 |

即便官方资料支持某种能力，状态仍是“文档证实，实机待验证”。替代头显、手机麦克风和模拟回放必须在结果中披露，不能混写成候选消费眼镜上的实现。

## 4. 日常自我觉察的证据与风险

| ID | 主张／问题 | 证据与限制 | 研究中的处理 |
| --- | --- | --- | --- |
| S-01 | HR/HRV 能精确识别焦虑、愤怒或兴奋 | HRV-01 的 Apple ECG 研究关联很弱；HRV-02 的自然情境模型解释变异有限；两者也不是这些情绪类别的验证 | 称为可能有关的生理变化，不直接贴命名情绪标签；不借自己的心率判断他人的态度 |
| S-02 | 运动与心率共同变化证明是情绪导致 | 活动既可影响生理状态，也可影响测量；LI-05 实际报告动作干扰和误报 | 记录活动、佩戴和信号质量；错误时弃答；多模态一致不等于因果或真值 |
| S-03 | 检测到手部动作就检测到了“无意识” | EMG-01 不测量意识；LI-04 关注反思而非意识分类 | 动作发生、是否先前察觉、行为含义分别测量；后两项依赖个人叙述并保留不确定 |
| S-04 | fidgeting 越少越好 | LI-05 有自发利用挤压调节的报告；SREG-01 中自闭症成人描述自我调节作用，但不代表全部群体 | 不自动压制无害动作；由用户选择想理解的习惯与目标；不把动作计数降低当作成功 |
| S-05 | 提高觉察一定减少压力 | LI-04 为初步反思研究；LI-05 同时报告负担、尴尬和不想被提醒 | 同时记录有用性、烦扰、过度监测、关闭与退出；允许不介入 |
| S-06 | 生理反馈证明本系统有疗效 | HRV-03 单次短干预改善部分指标，未改善反刍；HRV-04 加反馈并未显著优于同一无反馈干预 | 不宣称治疗、预防或长期改善；本试点只评估可行性、体验及反馈时机 |
| S-07 | 八至十二人、约两周足够验证临床收益 | **不能**；是探索性资源与负担安排 | 以误报每小时、可用性、反思与自主权为重点；不以无显著差异宣称同效或安全 |
| S-08 | 自适应提醒等于已验证的 JITAI | METHOD-01 是设计框架 | 分开决策点、可用性、情境、选项和近端结果，后续再验证策略 |
| S-09 | 该模块必须接入主实验 | **不是既定设计** | RQ4 独立同意、招募、分析与决策；信号权限或负担未达标则延期，不阻断核心 |

## 6. 后续证据更新模板

每次新增可实现性或效果主张，至少记录：主张 ID、具体设备／模型版本、数据和任务来源、样本与排除、观察或测试方法、结果和不确定性、失败例、隐私处理、是否可公开，以及独立复查状态。

不能用模拟演示替代实机验证，不能用技术准确率替代用户收益，也不能用短期满意度替代长期安全或临床效果。合理的负面结果和无法支持的主张应保留在记录中。
