# 指标与分析计划

> 版本：v0.1｜2026-10-22｜方法草案，尚未预注册。
> 本文规定指标含义与分析边界，不声称已有数据、仿真结果、设备性能或统计显著性。正式研究前须冻结参数、代码与排除规则；更改须保留记录。

适用范围：[首年核心研究](./首年研究协议.md)及[独立可选日常支线](./生理与微动作探索协议.md)。个人资料和录音录像管理见[伦理与参与者材料](./伦理与参与者材料.md)。

## 1. 分析的优先级

| 层级 | 分析对象 | 优先结局/对比 | 可以支持的结论 |
| --- | --- | --- | --- |
| 主要 | DHH 受控回放 | C2 对 C0 的预先规定低歧义解释题准确率 | 共享字幕条件下补充线索策略的净影响 |
| 计划次要 | 同一回放 | C2 对 C1；努力、舒适度、打扰、错误依赖和控制感 | 策略的权衡；不能独立分解密度与校准机制 |
| 形成性/定性 | 共创与刺激回忆 | 需求、分歧、解释、恢复、控制与社会边界 | 有证据来源的设计指导，不以频数替代普遍性 |
| 技术 | 输入、候选和显示事件 | 错误、覆盖、时延、过时、未知状态与降级 | 真实验证过的系统能力与失败范围 |
| 可选可行性 | 短期现场使用 | 断连恢复、沟通修复与接受度 | 可行性，不是长期参与或福祉效果 |
| 独立探索 | P0/P1/P2 日常模式 | 已确认不合适提示、帮助、负担与控制感 | 个人化策略的可行性，不是临床疗效 |

所有 C0/C1/C2 条件共享所选字幕版式、ASR 回放、说话人映射与基础故障时序。该实验不识别空间布局的独立效果。生理支线不并入核心研究的主要假设或样本量。

## 2. 最小分析单位与日志字段

使用随机研究编号，身份联系表不进入分析表。事件日志默认只保留必要的结构化字段；原始内容属于另行同意的数据层。

| 单位 | 必要字段 | 作用 |
| --- | --- | --- |
| 参与者 | 研究编号、阶段、需要的沟通安排、可选字幕经验、退出/同意状态 | 描述样本与聚类，不创建人格档案 |
| 会话/区块 | 会话编号、条件、顺序、材料集合、配置版本、开始/结束/暂停 | 区分条件、学习与可用暴露时间 |
| 解释题 | 项目编号、对话编号、参考答案版本、分配条件、作答、缺失原因 | 主要结局与项目重复 |
| 候选线索 | 事件编号、类别、来源事件、说话人/未知、证据时间、有效期 | 明确门控之前的共同候选池 |
| 决策 | 后端/模型/提示词/策略版本、输出、耗时、抑制原因、异常 | 区分模型解释与控制层行为 |
| 显示 | 显示请求/确认、可测实际呈现、结束、字幕占用、用户操作 | 区分被生成、被提交、被显示与被用户报告看到 |
| 日常支线 | 源样本时间、接收时间、信号类型/质量、可用窗口、活动背景、动作特征、触发来源 | 分开测量数据新鲜度、候选与提示 |
| 自报 | 提问来源、时间、所指事件、响应时间、答案或跳过 | 区分随机采样、算法触发及主动记录 |

字段可以省略不必要的内容，但不能省略失败、缺失或未知状态。研究日志不得把原始生理序列、私人文字或身份信息写入公开仓库。

## 3. 解释准确率与缺失数据

### 3.1 主要结局

每个预先指定、低歧义题的结果为正确或错误。正确答案与评分规则在查看主研究结果前锁定。多项选择中的“无法判断/不知道”是有效作答；对于确有清晰参考答案的主要题，按错误计分，而不是排除。

描述性准确率为：**正确题数 / 已获得可评分作答的主要题数**。同时报告：分配题数、实际呈现题数、可评分题数、各类缺失数和每人的完成比例。不能通过缩小分母掩盖某条件下较多的故障或退出。

模型以题目级作答为单位并按分配条件分析，不只分析“认真看过提示”或“相信模型”的人。技术未呈现、退出、拒答、未完成、日志丢失分开编码；不把技术故障自动归为理解错误，也不把未作答自动当成正确。

主要估计使用有观察结果的分配题并明确其缺失假设；补充报告各条件缺失模式。敏感性分析包括对非技术性缺失采用预先规定的保守计分和上下界情景。若缺失明显与条件或负担相关，应降低因果结论强度，不能仅用完整案例掩盖问题。

### 3.2 模型与报告

主分析采用二项混合效应模型，固定效应至少包含条件与区块顺序，随机效应考虑参与者和项目；按实际材料结构进一步处理对话层聚类与参与者的条件差异。材料集合和其他设计变量只按冻结计划加入，不逐步挑选显著协变量。

正式冻结时写明完整模型公式、估计方法、区间方法和收敛标准。若随机斜率或对话层结构不能稳定估计，按事先规定的简化顺序处理；保持参与者和项目聚类信息，并报告简化及敏感性结果。若稀疏/完全分离持续存在，可使用预先指定的正则化模型或按参与者、项目结构重抽样的描述估计，不以哪个方法给出更小 p 值决定。

优先报告 C2−C0 的边际准确率差、95% 区间及各条件分布；若使用优势比，同时给出便于理解的绝对尺度。主要检验若采用频率学框架，预设双侧 0.05；C2−C1 等次要准确率比较作为明确的比较族进行 Holm 调整。其他探索性结果给出估计与区间并标注探索性，不以未调整的多次检验宣称确认性发现。

不显著不等于等效、不劣或安全。未预设并论证界值时，不进行事后“非劣效”解释。

### 3.3 暂定样本量的论证

约 24 人是招募起点，不是功效结论。试运行主要用于检查任务、时长、可测性、上下限效应和数据缺失，不用少量参与者的效应量保证主研究功效。

正式规划应覆盖多个合理场景：基础准确率、值得检测的绝对差异、参与者与项目变异、项目数量、顺序效应及退出率。对计划的平衡分配和分析模型做仿真，报告达到的区间宽度或功效范围、假设来源与不利场景。仿真未运行前不得填写“80% 功效”等结果。

若资源不足以得到有意义的精度，就调整问题、增加经批准的招募或将研究明确定位为探索性。不得根据阶段性显著性随意提前结束或持续追加人数。

## 4. 次要体验与错误依赖指标

| 指标 | 操作定义与分母 | 注意事项 |
| --- | --- | --- |
| 主观努力 | 每条件结束时，使用同一简短、语言适配的量表；报告完成者与缺失者数 | 自编条目须标明未验证，不能冒称临床或认知诊断量表 |
| 视觉不适 | 每区块及停止时记录程度、类型、休息/终止 | 中途停止者不能被排除后得出“舒适”结论 |
| 控制感 | 能否关闭、理解不确定性、自由忽略及纠错的同一组评价 | 更高信任不自动等于更好；区分理解与过度依赖 |
| 提示暴露密度 | 实际呈现线索数 / 有效回放分钟；同时报告生成、提交和抑制数 | 不把生成次数当作用户看到的次数 |
| 显示占用 | 预先定义的辅助区像素/面积占比及其时间分布；字幕区另记 | 是界面负担代理，不是认知负荷或视线测量 |
| 打断/操作 | 用户明确标记的打断、暂停、关闭、纠错次数 / 有效会话时间 | 关闭可能表示成功的自主控制，不一律判为失败 |
| 错误线索依赖 | 在实际暴露且可判断的错误探针中，作答跟随错误信息的次数 / 对应有效探针数 | 选择性暴露有偏；同时报告全部分配探针和暴露率 |
| 恢复 | 识别不一致、转回字幕、请求澄清或关闭的行为与时间 | 未恢复、未注意到、未触发、不可观察分别编码 |

错误探针是单独的次要数据集。对过时输入，首先测量系统是否正确阻止显示；不为增加错误依赖样本而关闭产品保护。

## 5. 技术指标：错误与覆盖必须成对报告

| 指标 | 定义 | 报告方式 |
| --- | --- | --- |
| 候选覆盖 | 有候选输出的可标注参考事件数 / 全部可标注参考事件数 | 按类别、说话人、清晰/模糊输入分层 |
| 呈现覆盖 | 实际呈现的符合基础有效性要求候选数 / 全部此类候选数 | 配合各类抑制理由，不以低覆盖换取漂亮错误率而不披露 |
| 选择性错误率 | 实际呈现且有参考标签的错误线索数 / 实际呈现且有参考标签的线索数 | 参考不确定者另列；不得强制当正确或错误 |
| 说话人归属 | 正确归属的可评分话轮数 / 有归属输出的可评分话轮数 | 同时报归属覆盖、未知比例和错误附着次数 |
| ASR 误差 | 按研究语言冻结 CER 或 WER 规则；包含标点/数字规范 | 回放条件间应相同；现场质量只作实际记录 |
| 字幕稳定性 | 被修改过的已提交片段数 / 全部已提交片段数 | 临时文本正常更新与已提交后修订分开 |
| 决策失败率 | 超时、格式错误、无可用结果或服务失败次数 / 全部发起的决策请求数 | 弃权是允许的策略结果，不混作系统失败 |
| 过时抑制 | 因超过有效期被挡住的候选数 / 到达控制层时已过时的候选数 | 分母为零时记“不适用”，不是 100% |
| 过时泄漏 | 呈现时已过期的线索数 / 有可核对时序的已呈现线索数 | 时间无法对齐者单列，不默认为新鲜 |
| 字幕可用率 | 可供阅读的字幕时长 / 计划提供字幕的有效任务时长 | 区分静音/无语音、暂停和技术不可用 |

模型的正确性、是否呈现、是否被注意到和是否被采纳是不同变量。每个阶段记录独立状态，不能用点击或停留时间替代所有环节。

## 6. 时间戳、延迟与失效数据

建议保留以下时点：源事件/源样本时间、足够证据形成时间、字幕提交、决策请求与返回、显示请求与确认、可测实际显示、过期时间、手机收到数据时间和用户响应时间。

| 时间指标 | 计算起止 | 限制 |
| --- | --- | --- |
| 语音到字幕延迟 | 预定语音参考时点至字幕提交/可测显示 | 参考点按词尾或话轮规则冻结，不混用 |
| 证据到线索延迟 | 足够证据形成至可测线索显示 | 不把尚未发生的语音上下文算成模型延迟 |
| 后端延迟 | 请求至响应/超时 | 不等于端到端体验 |
| 显示时线索年龄 | 显示时点减其依据事件时间 | 与有效期结合，不能只报告请求很快 |
| 生理数据年龄 | 瞬时样本用决策 / 呈现时点减源测量时间；窗口特征减映射后的源窗口结束时间 | 生成、发布或接收时间不能冒充测量时间；映射未知则年龄未知 |
| 传输延迟 | 下游接收时间减源/上游时间 | 须有跨设备时钟对齐依据 |

使用可验证的时钟同步或共同时间基准，记录偏移、漂移和同步误差。没有实际显示传感或确认能力时，只能报告渲染提交/设备确认时间，不声称测到了光学呈现时刻。时钟失配不能用截断负值的方式掩盖。

对成功事件报告中位数、p95 和分布，同时报告超时、缺失和未完成比例。仅报告成功调用的 p95 会漏掉最差情况；其分母须说明。初始“足够证据后额外线索延迟 p95 低于一秒”只是工程目标，不是已达成指标或厂商保证。

运行时滚动上下文初始为可配置的 90 秒内存缓冲，不自动构成持久记录许可。具体线索有效期可能远短于缓冲长度；不能因为事件仍在缓冲中就继续呈现旧线索。

## 7. 不确定性与校准

先区分：有依据的声学量、任务推断、API 分数和呈现决策。Jev 的置信统计量不直接作为“正确概率”显示或评分。

若仅有未校准分数，报告随阈值变化的覆盖—错误曲线、类别错误和弃权情况；不直接计算并解释为概率校准。只有建立了有语义、经独立数据检验的概率输出后，才使用可靠性分箱、Brier 分数等诊断，并报告分箱人数和不确定性。独立二元回答不自动组成和为一的多分类概率。

训练、阈值选择、校准和最终测试分开。离线语音模型按说话人/对话隔离；日常个体模型按日期/会话隔离。测试集不能用于不断挑选更漂亮阈值。

## 8. 独立日常支线的操作指标

### 8.1 分母和可用时间

- **计划佩戴时间**：参与者同意并计划使用的时段，不包含睡眠或不允许采集时段，除非另行明确纳入。
- **实际佩戴时间**：依据经验证的佩戴状态或记录确认的时间；无法确定时单列。
- **可分析时间**：实际佩戴中满足冻结质量、样本年龄和时钟要求的时间。无数据时不能视作“平静”。
- **共同可比窗口**：离线 P1/P2 比较中，所需共同输入均可用且使用同一时间网格的窗口。新增动作特征造成的覆盖损失另报，不能悄悄只选更容易的 P2 时段。
- **实际提示数**：真正呈现的支持询问，不含算法候选或随机研究问卷。随机自报、触发后自报及用户主动标记分开统计。

### 8.2 日常结局

| 指标 | 操作定义 | 解释边界 |
| --- | --- | --- |
| 已确认不合适提示率 | 用户明确表示无关/时机不对的提示数 / 可分析佩戴小时 | 是已确认事件的率；未回应不能当作无关或有用，须同时报告回应率与可能界限 |
| 提示适合度 | 已明确评价为适合的提示数 / 已有效回应的支持提示数 | 可能存在回应选择偏差，不替代每小时负担 |
| 动作检出 | 在有独立验证的片段中，分别统计精确率、召回及普通任务误检 | 自然数据无完整真值时，不声称测得全天召回 |
| 用户期望但未提示 | 随机自报或主动标记中报告希望支持，但匹配窗口无提示的事件 | 自报非无误差真值；不能据此估计所有未观测时刻 |
| 近期主观帮助 | 预定反馈窗口内的帮助、干扰及继续活动评价 | 逾期回答记为回顾性资料，不冒称即时结果 |
| 控制与负担 | 每日简短评价、静音、关闭、删除及退出原因 | 关闭不等于“不依从”；保持用户选择 |
| 通信/手语混淆 | 已验证的正常沟通活动被当作目标模式或支持触发的次数 | 严重案例先触发修订或暂停，不能只平均化 |

自报匹配窗口、迟到标准和事件合并规则在试运行后冻结。重叠触发合并为一个事件时，应保留原始候选计数，避免把同一次状态重复算作多个成功。

在线 P0/P1/P2 使用同一支持界面、内容、研究自报安排及提示上限，报告实际提示次数。离线 P1/P2 在共同未见数据上匹配可行提示预算并保持同样冷却规则；预算相同不表示所有日子都必须用满。

小样本分析以每人、每天分布和配对差异为主；使用重复测量模型时将参与者和日期/区块结构纳入，不能把成千上万个窗口当作成千上万名独立参与者。置信区间宽或自然数据标签不足时，应报告不确定性，不用显著性包装可行性。

评估期冻结个人规则。若不得不更新模型，应开始新版本阶段并记录影响，不将更新前后混成同一条件。提示暴露后的信号不能作为未干预自然基线。

## 9. 定性分析与整合

共创、主研究访谈、现场伙伴访谈及日常回顾分开标记来源。使用透明的主题分析流程：熟悉材料、编码、整理主题、检查负例、讨论研究者立场和保留解释轨迹。若选用反思性主题分析，不机械地把编码者一致率当作其质量证明；若采用代码本分析，则另行说明编码训练与一致性方法。

不把主研究的短访谈混作新的饱和性主张。区分参与者陈述、研究者解释和设计建议；引用须获得相应许可并检查组合细节的回识别风险。

定量与定性整合优先解释矛盾：准确率提高但更费力、用户偏好字幕单独模式、错误被识别却仍影响对伙伴的看法、自动模式被关闭但手动支持有用。不能只选支持产品愿景的引语。
