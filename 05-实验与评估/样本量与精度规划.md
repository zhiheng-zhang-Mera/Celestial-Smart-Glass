# 样本量与精度规划

> 版本：v0.2｜2026-10-22｜状态：设计计算已运行；研究仍为 PROPOSED。
> **这里只有假设驱动的合成计算，不含参与者数据。** 计算保留交叉随机效应和实验分配结构，但没有拟合最终 GLMM，也没有计算其功效或区间覆盖。不得把下表写成“24 人具有 80% 功效”。

## 1. 当前建议

保留约 **24 名随机分配参与者作为首年初期可行性与估计型研究的起点**。36/48 人是供导师与资源讨论的敏感性场景，没有擅自修改主研究承诺。

在一组中等异质性、C0=70%、C2=80%、完整观察的假设下，24 人/每人36题的描述性配对准确率差，在重复抽样中的 95%绝对误差分位数约 **7.2 个百分点**；36 人约 6.0，48 人约 5.1。它提示24人不适合承诺精确识别仅5个百分点的收益，但不能由此直接推导某个正式检验的功效。

**该误差分位数不是实际研究的95%置信区间半宽。** 它使用已知合成真值，描述在假定世界里重复进行研究时，估计偏离真值的范围。最终 GLMM 的估计效率、有限样本偏差、收敛和 bootstrap 区间覆盖还要另测。

## 3. 数据生成模型和估计器

### 3.1 与设计相符的结构

每人36题，分为18段对话、三集合；每条件12题。六行平衡块重复后，每条件×集合及集合×时期精确平衡。同一人不重复看同一题，同一题跨人出现在三个条件中。

二元作答由 logistic 模型生成，包含独立正态的：参与者截距、题目截距、对话截距、参与者×对话截距，以及参与者和题目的 C1/C2 随机斜率。每次重复重新抽取参与者和材料效应，因此不是只对这一套固定题目给条件化的乐观精度。

时期与集合固定效应均为 −0.10、0、+0.10（log-odds）。用60点 Gauss–Hermite 积分及数值求根，校准各条件的总体平均正确率；不把 logistic(固定截距) 当作已经边际化的正确率。

本轮题型固定效应设为零，不模拟条件×题型/时期交互、非正态效应、真实设备故障链或不同拆分会话的携带效应；这也是为何它不能替代完整分析流程验证。

C1 的设定平均提升是 C2 的一半，纯粹用于完整三条件数据生成，不是对 C1 表现的证据或研究预期。主要输出仍只针对 C2−C0。

### 3.2 异质性假设（均为 log-odds 标准差）

| 假设 | 参与者截距 | 题目截距 | 对话截距 | 参与者×对话 | 参与者条件斜率 | 题目条件斜率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 低 | 0.40 | 0.35 | 0.15 | 0.10 | 0.15 | 0.10 |
| 中 | 0.75 | 0.60 | 0.25 | 0.20 | 0.35 | 0.25 |
| 高 | 1.00 | 0.80 | 0.40 | 0.35 | 0.60 | 0.45 |

这些不是从试点、DHH 群体或既有论文估计的参数；是为了避免只展示一个有利场景而设置的敏感性范围。不能把“中”称为最可能或已经验证的世界。

### 3.3 被评估的描述估计器

每次合成研究计算每人 C2 正确率减 C0 正确率，再对人等权平均。存在缺失时，使用该人各条件的可观察题；没有 C0 或 C2 可观察题者不能贡献配对差，并计入缺失概况。

这个描述估计器不是主 GLMM 的标准化估计器。六行分配保证上述二因素边际平衡，但不完整交叉条件×时期×集合；logit 非线性下，等权配对均值可能相对设定的总体标准化真值有少量设计/非线性偏差。程序并未把它假定为零，而是将实际偏差计入误差汇总；最终模型的表现仍须另行验证。

输出包括：平均估计、偏差、重复抽样标准差、误差2.5%/97.5%分位数、绝对误差95%分位数、有效人数与答题数、Monte Carlo 均值误差和近似 SD 误差。

不拟合 GLMM、不输出 p 值或“拒绝率”。因此本计算不能替代正式分析中的混合模型、bootstrap、缺失机制假设或参数识别诊断。

## 4. 主要精度敏感性结果

下表为 **95%绝对重复抽样误差分位数，单位：百分点**，仅在相应合成假设下解释。为了可读性保留一位小数；CSV 保存更完整数值。

| 合成假设 | N=24 | N=36 | N=48 |
| --- | ---: | ---: | ---: |
| 低异质性，70%→80%，36题 | 7.0 | 5.8 | 4.9 |
| 中异质性，70%→80%，36题 | 7.2 | 6.0 | 5.1 |
| 高异质性，70%→80%，36题 | 7.6 | 6.2 | 5.8 |
| 中异质性，零平均效应，36题 | 7.6 | 6.0 | 5.2 |
| 中异质性，70%→75%，36题 | 7.4 | 5.9 | 5.4 |
| 中异质性，70%→85%，36题 | 7.2 | 5.6 | 5.1 |
| 中异质性，55%→65%，36题 | 8.3 | 6.7 | 5.7 |
| 中异质性，85%→95%，36题 | 5.3 | 4.4 | 3.9 |
| 中异质性，10%整人退出+10%题级 MCAR | 8.0 | 6.6 | 5.7 |
| 中异质性，错题更常缺失的 MNAR 示例 | 10.4 | 9.3 | 8.6 |
| 中异质性，70%→80%，扩至72题 | 5.3 | 4.4 | 3.8 |

4000 次重复使中等场景 N=24 的均值 Monte Carlo 标准误约0.06个百分点，SD 的正态近似 Monte Carlo 误差约0.04个百分点。误差分位数还受离散作答和有限重复影响，不应过度解读第二位小数。模拟参数的不确定性远大于这些数值计算误差。

高基础准确率时绝对方差较小，不意味着可以用天花板任务“证明系统有效”；这时可改善的空间也更小。更多题可以提高一些设计精度，但会增加疲劳、材料制作与访问服务成本；72题不属于当前主方案。

## 5. 缺失不只是样本量问题

MCAR 情景独立移除约10%的参与者，再独立移除约10%的题级回答。这是计算上的假设，不是对真实退出机制的承诺。

MNAR 示例如下：所有作答基础缺失概率5%；C2 中原本答错的题额外增加25个百分点缺失（总计30%）。可观察数据中的 C2 效果因而被抬高。

| 人数 | C2−C0 估计偏差（百分点） | 95%绝对误差分位数 |
| --- | ---: | ---: |
| 24 | +4.1 | 10.4 |
| 36 | +4.2 | 9.3 |
| 48 | +4.1 | 8.6 |

增加人数降低了随机变异，但没有消除约4个百分点的选择偏差。现实中看不到缺失题的真实正确性，所以必须记录原因、保留用户退出权并做敏感性分析，而不是假定缺失者和完成者一样。

## 6. 不改人数前提下的资源决策

| 讨论目标 | 当前证据支持怎样的决定 | 不能据此做的事 |
| --- | --- | --- |
| 首年完成有边界的可行性/估计研究 | 暂留24人，诚实接受在多种假设下约7–8个百分点的设计误差半径 | 不许诺稳定识别5个百分点的收益 |
| 希望描述估计的误差接近±5个百分点 | 在主结果不可见时讨论36/48人、材料数量及访问资源；48人中等场景接近但并非保证 | 不在看见主结果后加到显著为止 |
| 招募人群困难 | 优先保障DHH参与和访问支持，必要时定位探索性并明确精度 | 不替换为便利听力正常样本却沿用DHH结论 |
| 增加题数 | 72题只作资源敏感性，须重新试运行疲劳与会话时长 | 不把更多相关题当成更多独立参与者 |

最终 N、固定招募截止规则、可接受精度与是否保留确认性措辞，由导师讨论与实际招募条件共同确定，必须在主要结果可见前记录。因风险或设备故障暂停是独立机制，不能与效果驱动的停止混在一起。
