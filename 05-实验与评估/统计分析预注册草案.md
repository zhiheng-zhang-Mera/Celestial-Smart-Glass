## 1. 研究问题、数据层级与固定范围

主要问题：在共享字幕基础上，不确定性与显示负担门控的补充线索策略 C2，是否改变相对字幕单独模式 C0 的低歧义理解准确率？关键次要比较为 C2 对 C1（基础调度辅助：相同候选池，在共享有效性、容量与调度约束下呈现，不作额外选择性门控）。

三个条件共享 ASR trace、所选布局、说话人映射、预定基础故障时序及个人初始设置。C1 不保证显示全部有效候选；与 C2 共用槽位、队列、TTL、冲突与用户关闭规则。中途关闭/修改不静默重开、不按事后曝光排除。比较不识别空间布局的独立效果，也不分解密度与校准机制。

拟议数据为约 24 名随机分配的 DHH 成人，每人 18 段对话、36 个二元主要作答，每条件 12 题；题目嵌套于对话，同一题跨参与者分配到不同条件。约 864 条作答不是 864 名独立参与者。

独立探针、形成性访谈、现场子集和 HR/EMG 支线不并入主要结局或合并扩大样本。参与者数量可在主研究开始前经导师/资源讨论修改，不能根据中途效果大小或显著性追加。

## 2. 估计目标（estimand）

主要目标为 **Δ20 = μ2 − μ0**：在规定目标人群和这类低歧义材料总体中，对三个时期、三个材料集合及三类题等权标准化后的平均正确概率差。以百分点报告；正值表示 C2 较高，负值表示 C2 较低。

估计包含用户关闭、弃权和现实可用的策略降级，是按分配策略的效果，不是只在“看到并相信提示”的人中估计效果。没有主张长期社会参与、情绪调节或所有 DHH 人群的普遍效果。

次要准确率估计为 Δ21 = μ2 − μ1 和 Δ10 = μ1 − μ0。固定效应的条件优势比可补充报告，但它不是边际风险差；尤其存在条件随机斜率时，固定 log-OR 为零与边际准确率差为零不能简单互换。

## 3. 评分、分析集与排除

### 3.1 作答

按冻结答案，正确选项记 1，错误实质选项或“无法判断/不知道”记 0。拒答、跳过、退出、未呈现和日志丢失分别记缺失。评分者不能根据条件改变答案或给提示相符的回答加分。

主要分析使用所有符合入组、同意仍有效且至少有一条可评分主要作答的已随机分配参与者；不要求每人答满，也不因表现低、字幕经验、关闭提示或不相信模型而排除。

### 3.2 允许的行政/技术排除

- 未同意、同意撤回使数据不可继续使用、重复参加或入组资格记录客观错误，依批准流程处理并报告人数，不公开身份细节。
- 基础任务文件错误、错误素材版本或关键回放未发生，使某题根本没有按预定任务呈现：标记该题技术缺失，不自动删除整个人。
- 模型超时、合法弃权、线索被抑制、用户关闭或单独提示未成功显示，是策略实施过程的一部分；只要基础任务已呈现且能作答，保留作答并记录失败，不以“技术异常”过滤掉差结果。
- 同一条作答重复写入时按事件 ID 和确认时间去重，保留审计；不挑选正确版本。
- 客观答案/材料错误由不知道条件和结果的人员按预设准入规则处理，统一影响所有条件；任何接触结果后的修订均保留原评分和敏感性版本。

报告从接触、同意、随机分配、实际呈现至分析的流程；未获得任何作答者仍计入随机分配与缺失概况。初始 N=24 指随机分配目标，而不是事后挑出 24 个完整或高质量完成者。随机分配后退出不凭结果替换；此前未进入主要任务的准备失败可按预先规则重新安排。

## 4. 主要 GLMM 的具体形式

二元结果使用 logit 链接。C1、C2 为数值型 0/1 指示变量，C0 为参考。主模型 M0：

```r
correct ~ C1 + C2 + factor(period) + factor(material_set) + factor(item_type) +
  (1 + C1 + C2 || participant_id) +
  (1 + C1 + C2 || item_id) +
  (1 | clip_id) +
  (1 | participant_id:clip_id)
```

参与者与题目的条件随机斜率允许个体和材料的策略反应不同；对话及参与者×对话截距处理同一短对话的两题相关。主模型的随机效应相关固定为零，这是事先的简化假设，不是看显著性后决定。材料集和题型按固定设计变量处理。

拟用 R 的 lme4::glmer，family=binomial(link="logit")，Laplace 近似（nAGQ=1），bobyqa，maxfun=200000。正式执行记录 R、lme4 和依赖版本、随机种子、优化器与所有警告。以上是计划分析实现，本轮并未在实际或模拟数据上完成这个模型的拟合验证。

### 概率标准化

对每个条件 c、时期 p、集合 s、题型 t，计算固定线性预测，再对该条件的参与者/题目/对话随机效应分布积分，最后对 27 个设计组合等权平均。采用固定的 Gauss–Hermite 积分节点或经数值检验足够精确的等价方法。

六行分配精确平衡的是条件顺序、条件×集合及集合×时期，不是条件×时期×集合的完整三因素交叉。以上标准化因此依赖所规定的加性固定效应及随机结构，包含对未完整交叉单元的模型预测；不声称本规模已识别条件×时期/题型交互。必要的交互探索应清楚标为模型敏感性，不能事后重新定义主要目标。

不能把所有随机效应设为零后直接取 logistic 值，称为总体平均准确率；也不能平均每个参与者的条件 OR 后当作风险差。对外报告 μ0、μ1、μ2 和各 Δ，保留条件正确率及人数/题数的描述表。

## 5. 区间、主要对比与多重性

以估计和不确定性为主，不以“p 小于 0.05”决定研究价值。

- **唯一主要对比 Δ20：**报告双侧 95% 参数 bootstrap 百分位区间及点估计。
- **次要准确率族 {Δ21, Δ10}：**各报告 97.5% 区间（Bonferroni，每个区间 α=0.025），保留 Δ21 的关键次要地位。
- **体验、探针、分层、现场与日常支线：**描述性估计和明确标注的区间，不宣称确认性 H2 显著或把未校正探索当作主要发现。

上述区间族的控制分别定义；不能声称所有跨文档分析共享一个已控制的总体家族错误率。若区间跨零，结论是当前数据与多种效应相容，不是等效、不劣、安全或没有需求。没有提前论证界值，不做事后非劣效结论。

### 参数 bootstrap 的执行约定

参数 bootstrap 重新生成随机效应和二元响应，语义与 bootMer 的 parametric、use.u=FALSE 一致；固定种子，**固定 2000 次尝试**。固定模型能稳定复拟时可用 bootMer；bootMer 本身不会自动切换降级模型。若要执行第 6 节的模型降级路径，须显式编写 simulate + 同一拟合/诊断包装器，并在每次重复中执行已冻结的诊断与降级规则。每次拟合后用相同标准化函数产生 μ 和 Δ；不是保持既有随机效应不变，只重抽响应。

保留全部警告、失败原因、边界方差和成功次数，不将失败静默删除后无限补到“想要的 2000 次”。少于 1900 次有效重复时，该区间标为未通过预设计算检查，先按第 6 节处理，不提供确认性区间结论。即使失败较少，也报告比例、潜在选择影响及区间端点的 Monte Carlo 不稳定性。最终计算流程需在冻结前用模拟数据检查覆盖与失败率；本轮的设计精度模拟没有完成这一步。

## 6. 收敛、奇异性和固定的降级路径

首先核对数据、编码、设计矩阵与重复项。优化器返回成功不等于模型一定可解释；保留梯度、Hessian、isSingular 及估计稳定性诊断。[1]

1. 运行 M0；检查是否有错误编码、完全分离、收敛警告或实质无法识别。
2. 不改变模型，收紧容差并用预先指定的第二优化器 nloptwrap 复核；记录目标函数与系数差异，不根据效应大小选择“最好”的优化器。
3. 边界方差/奇异性本身不是自动删项许可。若参数稳定、无实质数值失败，可保留边界解并报告其限制；不能把 Wald 表格当作无条件有效的证据。[1]
4. M0 经复核仍不可估时，先移除参与者×对话截距形成 M1；仍失败则同时移除参与者和题目的 C1 随机斜率形成 M2，保留 C2 随机斜率、参与者/题目截距和对话截距。每一步记录原因。
5. 若需要移除主要 C2 的反应异质性才能得到稳定结果，不再把截距模型包装为原确认性分析。报告无法可靠拟合、描述性配对差异，并进行按参与者和对话（两题成组、按集合分层）交叉重抽样的探索性敏感性分析；明确它不是已经验证覆盖率的替代确认性检验。

bootstrap 重复执行同一已冻结的拟合/降级诊断流程，并统计各结构出现比例。若模型结构不稳定、bootstrap 失败过多或主模型只能靠强烈简化成立，结论定位为探索性。不得按显著性、AIC 最低或效应方向临时挑选路径。

## 7. 缺失数据与敏感性分析

主模型使用实际观察到的可评分作答，其推断依赖给定纳入变量与随机结构后缺失机制可忽略的假设；这一点不能由数据自动证明。

预先报告每条件、时期、材料集合的分配/呈现/回答/缺失数及缺失原因。至少给出以下敏感性结果：

1. 将非技术性未回答按条件给出透明边界：Δ20 的最坏（低界）情景将 C2 缺失作答设错、C0 缺失作答设对；最好（高界）情景将 C2 缺失作答设对、C0 缺失作答设错。并附各条件全错/全对结果；所有条件同时全错并非差值的最坏边界。技术未呈现不默认为理解错误。
2. 在每条件至少 8/12 题可评分者中重复估计，明确这是完整度敏感性子集，不替代主要分析集。
3. 按退出、主动关闭、设备故障分别描述缺失与暴露，不把不回应当作接受或平静。
4. 模式混合情景：假设缺失作答相对可观测作答的 log-odds 下移/上移 0.5 和 1.0，分别报告 Δ20 如何变化。该参数是敏感性假设，不声称从缺失数据中识别。

若不同条件的缺失与负担明显相关，或 MNAR 场景能改变结论，应降低结论强度。样本量规划中的错题更常缺失例子展示的是偏差风险，不是用增大 N 可以解决的问题。

## 8. 体验、探针与定性材料

六项自编体验条目单独分析，不合成为未经验证的“可用性总分”。报告每条件分布、中位数、作答/不适用数和适当的个体配对摘要；有足够数据时可作有序混合模型探索，但不替代主要二元结局。

E2/E5 在无提示的 C0 中可以不适用，不能编码为 0 来制造更好/更差的对照。主动关闭功能可能体现自主控制，不一概计作失败。

六个恢复探针含两个正确、两个可恢复错误、两个合法抑制示例；按类别在 C1/C2 间平衡分配，不强制曝光。分别报告所有分配、实际呈现和报告注意到的计数与逐例叙述。示例数量及非自然抽样不支持泛化识错/依赖率；错误暴露后的反应还有选择条件，不能直接当作门控的因果安全效应。过期输入主要检查硬规则是否阻止显示。

定性材料采用透明主题分析，区分参与者叙述、研究者解释和设计建议；保留负例、群体差异和设计决策轨迹。伙伴材料先独立分析。分析人员、资料范围、是否采用反思性或代码本主题分析在正式冻结时确认，不把两种方法的质量标准混用。

## 9. 资源决策与停止

在主研究第一个结果不可见时，依据[已运行的设计阶段敏感性计算](样本量与精度规划.md)、导师讨论、沟通服务与招募资源，确定 N、材料数量和精度目标。当前仍保留约 24 人的初期可行性/估计型定位，36/48 只是供讨论的场景。

按预先确定的随机分配人数或批准的招募截止日期停止；日期和人数规则在正式预注册中明确。研究中不做未规划的中期效果检验，不因结果“接近显著”扩招；风险或平台故障导致的暂停独立于效果停止规则。

材料变更、模型/策略版本更换或设备路径更换如实记录。已开始主要采集后，不把不同版本静默拼成同一确认性研究。
