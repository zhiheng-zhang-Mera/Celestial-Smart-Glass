## 2. 无障碍、主体性与研究关系

参与者自行决定是否希望用字幕，不把聋人或重听者视为同质群体，也不把听力差异等同于心理疾病。无需默认提供听力诊断、病历或不必要的健康史。

让参与者选择访谈方式、用语、休息和访问支持。尽量维持通常使用的助听设备、手语、字幕或其他安排；如某个实验设置暂时无法兼容，先讨论替代方式，不将无障碍需求作为负担转嫁给参与者。

允许单独表达对伙伴或系统的担忧。伙伴可以对自己的录音录像及参与作出选择，但不能代替有同意能力的成年佩戴者决定个人辅助偏好。研究者须避免因导师、教师、雇主或熟人关系造成隐性压力。

## 3. 数据流与最小化原则

核心数据流为：已同意的对话或回放 → 音频/转写及必要的说话人、声学事件 → 暂时会话状态 → 结构化决策 → 眼镜呈现。社会解释不得反向改写原始字幕。

日常支线另有：获授权的源样本/动作特征 → 时间与质量检查 → 最小个人上下文 → 询问是否需要支持。默认无需持续日常录音录像，不建立旁人画像。

| 数据层 | 拟议处理方式 | 留存与撤回要求 |
| --- | --- | --- |
| 运行时滚动上下文 | 初始 90 秒、可配置、默认仅驻留内存，仅为当次处理 | 自动滚动覆盖，结束/停止后清除可控缓存；不是永久记录许可 |
| 可选研究录音录像 | 仅在明确必要并单独同意时保存 | 按批准的具体期限和用途保存；与运行时缓冲分开 |
| 结构化日志与答案 | 随机编号、必要事件/结果/失败，不默认附带完整原文 | 冻结机构批准的保存计划；删除/匿名化过程可核查 |
| 生理/动作数据 | 最小必要特征与时间质量信息；原始序列另行论证 | 独立同意、访问限制；精细时间线也可能敏感 |
| 身份联系与补偿资料 | 与研究数据分开、限制人员访问 | 依批准和行政要求确定期限；不公开，也不供模型学习 |
| 同意与撤回记录 | 由负责机构管理 | 为审计保留必要记录，不与公开分析数据混合 |

“内存缓冲”不自动保证操作系统、崩溃日志、云供应商或备份从不留存。技术审计必须检查这些路径；无法实现的删除或零留存承诺不能写入参与者材料。

使用 Jev 等外部服务前，须审查输入内容、日志、保存与删除、分包方、地区和安全措施。供应商宣称“不用于模型训练”不等于“零保存”。批准前仅用允许的材料开发，或采用获批准的本地/替代后端。TypeSafe 的现行说明需在启用前再次核查：https://help.typesafe.ai/articles/5974925716-how-is-submitted-data-used-or-retained

## 4. 拟议保存计划：不虚构固定期限

正式执行前，由机构为每类数据填写：目的、最小保存时长、最长时长、起算点、访问者、存储位置、撤回可执行期限、备份到期和删除责任人。招募材料和同意书必须使用同一批准版本。

当前仅提出以下生命周期原则：

- 不需要持久化的运行时内容不主动落盘；会话结束和用户停止时执行可验证的清理。
- 原始音视频在完成获批的转写/核查且无继续必要时优先删除；不能因为以后“可能有用”无期限保存。
- 将身份联系表与分析材料分开，尽早移除不必要的可识别内容。
- 保存最终分析记录的具体期限必须服从机构批准，不在本仓库预设为三年、五年或永久。
- 备份、供应商日志和导出副本也要纳入删除计划；对无法即时清除的副本如实告知。

参与者应知道：在数据仍可定位时可以申请删除；一旦按批准流程不可逆匿名化或形成无法分离的汇总，可能无法再找到个人记录。已公开的材料也可能被第三方复制。因此默认不公开可识别记录，任何公开影像/声音使用需要单独、具体同意。

## 5. 核心研究招募文本草案

### 智能眼镜字幕与对话提示研究

我们计划邀请成年聋人或重听者，帮助设计和评估智能眼镜上的字幕与可选对话提示。我们希望了解什么有帮助、什么会打扰，以及怎样让用户保持控制。

如果你年满 18 岁，自我认同为聋人或重听者，并愿意在口语对话中使用书面字幕，可能适合参加。不需要因为参加研究而提供听力诊断证明。是否合适还需结合主要研究语言、设备佩戴和你需要的沟通安排共同确认。

参与内容可能包括访谈与共同设计，或观看两至三人对话并体验不同提示方式。你可以只喜欢字幕、不喜欢任何补充提示，研究同样重视这样的意见。主研究初始预约约 80–90 分钟、包含休息，可根据需要讨论拆分；共创或试运行暂约 75–90 分钟，可选现场活动另约 45–60 分钟。正式时长以批准后的通知为准，不以预约长度要求你勉强坚持。

设备和 AI 会出错，可能出现视觉不适、分心或误导性的提示。本研究不是医疗诊断或治疗，也不评价你的社交能力。你可以随时暂停、跳过问题或退出。

我们将在正式招募时说明研究机构、审批信息、补偿、无障碍支持、数据处理和保存规则。**当前为审查用草案，尚未开放报名。** 请勿在公开仓库 Issue 或讨论区提交个人健康资料、联系方式或报名信息。

正式发布前补全：机构公开研究联系渠道、审批编号、主要语言、地点/远程方式、时间、补偿及沟通支持。不得用私人邮箱或未经确认的联系人占位。

## 6. 简短筛选与安排问题

仅通过批准的私密渠道询问必要信息：

1. 你是否年满 18 岁？
2. 你是否自我认同为聋人或重听者，并愿意在本次口语任务中使用字幕？
3. 你希望使用什么语言、沟通方式或访问支持？
4. 你平常是否使用字幕或助听设备？可以选择不回答细节。
5. 戴眼镜或阅读小屏幕是否需要调整、休息或其他安排？
6. 你是否参加过本项目的其他阶段或见过相关材料？
7. 你希望怎样安排时间、休息和联系？联系方式与研究答案分开保存。

不要默认收集诊断证明、完整病史、家庭住址、身份证号码或非必要的人口学信息。如确有必要，须说明研究目的并经审查。

## 7. 核心研究参与者说明书草案

### 我们邀请你做什么

你将看到或体验智能眼镜字幕，以及一些可关闭的补充提示。主要实验使用预录对话；可选的真实对话需要另外确认安排，所有会被处理声音或影像的人都要同意。我们会记录任务回答、必要的系统事件以及你愿意提供的意见。

主要任务暂有 18 段短对话、36 道内容问题；屏幕播放对话，眼镜显示字幕和可能出现的辅助，每段后在同一伴随界面作答。我们维持你通常使用的助听方式与舒适音量，提供需要的访问支持。你可以选择“不知道”，也可以直接跳过；两者会以不同状态记录，但都不影响补偿或受到尊重的权利。

### 你需要知道的限制

字幕、说话人归属和补充提示可能不准确、延迟、缺失或令人分心。它们不能告诉你别人真正的情绪或意图。某些低风险测试项目会专门检验错误提示的影响；开始前会告诉你提示可能出错，结束后会解释具体例子。

主要任务后可能有六个单独示例，包含正确信息、低风险错误和按保护规则不显示的情况。它们用于讨论你如何理解与恢复，不是测试你是否应该信任研究者；你可以拒绝其中任何例子。关闭辅助后研究者不会暗中重新开启。

### 你可以怎样选择

你可以暂停、要求休息、改用字幕单独模式、跳过问题或退出，不需要解释原因。研究者不会因为你不同意提示、关闭功能或回答错误而责备你。补偿依据批准后的时间和参与安排，不以成绩或服从程度决定。

### 风险和可能收益

可能出现眼部不适、疲劳、眩晕、分心、对提示的误解或隐私担忧。我们将提供停止控制和休息，不适时可以立即终止。你不一定从参与中直接受益；研究结果可能帮助改进未来设计，但没有保证。

### 哪些内容会被保存

必要的任务答案和系统日志以研究编号记录。原始录音录像、可识别引用和对外展示须分别征得同意。正式版本会列出处理方、保存期限、可撤回时间及删除方式；这些信息未填清楚前不能签署本模板。

### 你的资料会公开吗

默认不会公开你的姓名、联系信息、原始音视频、生理数据或精细时间线。论文可能报告汇总结果和经同意处理的引用。公开仓库主要存放协议、代码、模板和合成示例，不是研究记录存放处。

### 如果有问题或希望撤回

正式材料会提供负责机构的研究联系渠道及独立伦理咨询渠道。退出不影响你与机构、社区组织或研究者的正常关系。可删除范围和截止条件会在同意前说明，不能承诺在已不可逆匿名化或公开后仍能追回所有副本。

## 9. 可选日常支线说明与同意要点

### 说明文本草案

这个独立支线希望了解，你自己选定的动作模式与心率、活动背景，是否有助于在合适时机询问你需不需要支持。预计约两周，人数和安排仍需审批及技术验证。它不判断你是否“情绪异常”，也不要求你减少小动作或降低心率。

动作可能有助于舒适、专注或自我调节。你可以决定不追踪某种动作，关闭自动提示，或只手动记录。设备不一定能持续获得所需信号；没有数据或没有提示不表示你一定没事，也不表示你的体验不真实。

在不同条件中，系统可能不自动提示、只用 HR 加活动背景触发，或加入你选定的动作特征。若为离线比较需要在三个条件中记录相同的最小特征，研究者会明确说明并单独征得同意，不会因为 P0 不提示就让你误以为没有采集。

研究可能通过少量随机询问和触发后的询问了解你的体验。你可以不回答。不回应不会被自动解释为平静、无需求或不配合。提示可能让你更注意身体状态，也可能造成压力；若你感觉负担增加，请关闭或停止。

这不是医疗监护、诊断或紧急提醒服务。它不会保证发现健康问题，也不会向同伴、雇主或家属分享你的状态。

### 独立确认

- [ ] 我知道日常支线不是核心研究的必选部分，拒绝不影响其他参与。
- [ ] 我已了解实际可采集的信号类别、频率/缺失限制、处理位置与保存规则。
- [ ] 我自主选择了希望了解的动作；知道可以移除模式而无需减少该动作本身。
- [ ] 我了解各条件下哪些特征会被记录、哪些会被用于自动提示。
- [ ] 我知道自动支持默认关闭，开启后仍可设置安静时段、减少频率或立即关闭。
- [ ] 我了解随机自报、触发自报和私人注释的用途与删除方式。
- [ ] 我知道研究不以更少动作、较低心率或遵从提示评价我，也不做疾病或人格判断。

任何原始 sEMG、生理原始序列或短时验证录像，须在实际可用且必要时另列同意项目，不能在概念阶段笼统写成已经采集。

## 10. 访谈与刺激回忆提纲

### DHH 共创

1. 在两三人对话中，你最希望字幕解决什么？什么会让你分心？
2. 说话人不明确时，你希望系统怎样表达？
3. 重叠、强调、语速等信息，哪些值得显示？哪些应该完全不出现？
4. 如果系统不确定，你希望知道什么，而不是知道什么？
5. 你希望何时暂停、关闭或改变布局？怎样操作最省心？
6. 伙伴需要了解哪些信息？有没有你不愿意当着伙伴讨论的担忧？

### 主研究与事件回忆

1. 当时这个提示对你意味着什么？你用了哪些其他信息理解它？
2. 它有没有改变你对那句话或说话人的看法？
3. 你有没有觉得可以自由忽略它？是什么支持或妨碍了这种选择？
4. 提示缺失或被关闭时，你如何理解？
5. 如果提示错误，你怎样发现和恢复？是否错过了之后的字幕？
6. 哪些情况下你会选字幕单独模式？有没有我们没有提供的选项？

### 日常支线

1. 这个动作对你可能有什么作用？你希望系统不要干涉什么？
2. 这个例子中，动作、心率和你的感受是否一致？还有哪些解释？
3. 当时你有没有注意到这个动作？提醒是帮助还是额外关注？
4. 如果没有收到提示，你是否仍愿意主动记录或求助？
5. 有没有提示让你觉得被评价、需要表现得更平静，或压制有帮助的动作？
6. 你希望哪些数据不保留，哪些时间不采集？
7. 你愿意继续使用哪部分？完全不想继续也可以。

避免诱导式问题，例如“系统是不是让你更懂别人”“你减少了多少坏习惯”。研究者不得把不符合预期的回答改写成支持性反馈。

## 11. 停止、意外与退出操作

发生不适、困扰、隐私泄露风险或可用沟通支持丢失时，先暂停处理和显示，再询问是否休息、调整或结束。不要为了完成区块继续推送。记录最小必要事件信息，按机构流程报告，不在公开 Issue 中描述可识别参与者。

发现未同意的旁人声音/影像进入采集范围时，停止相关采集，隔离并按批准流程处理片段，不继续上传分析。核心研究通过私密受控环境降低这种可能性。

退出时执行：确认停止范围 → 停止新采集和提示 → 告知可定位数据与删除范围 → 在机构系统记录请求 → 执行并确认批准流程允许的删除 → 按既定规则结算补偿。若用户只关闭日常支线，不自动删除其愿意保留的核心研究参与记录；应明确询问范围。

日常支线中，自我监控压力、羞耻、沟通干扰或压制舒适动作的倾向均足以暂停自动模式，不需要达到某个心理测量分数。必要时仅保留用户主动功能或结束该支线。

## 12. 错误探针结束说明草案

今天部分低风险示例用于了解错误或不完整提示会怎样影响理解。它们不是对你判断能力的测试，也不说明你应该更信任或更不信任自己。

我们会指出相关例子，说明参考信息与系统输出有什么不同，并邀请你谈谈当时的体验。你可以不回答，也可以根据正式说明中的撤回规则提出数据处理请求。你指出错误、忽略提示、选择只看字幕或停止使用，都可能为设计提供重要信息。

如果刚才的体验让你不舒服，可以现在休息或结束；研究团队会按批准流程处理你的反馈。
