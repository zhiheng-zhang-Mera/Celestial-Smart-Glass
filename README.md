# Celestial-Smart-Glass｜智能眼镜研究与开发

**面向日常对话的自适应字幕、发言人关联与用户可控辅助线索。**

项目以 HCI 为主线，计划使用商业智能眼镜与手机构建可穿戴沟通辅助系统，并探索 Apple Watch 心率、活动信息与腕部肌电对佩戴者自我觉察的增量价值。第一年优先与选择使用字幕的聋人及重听者共同设计，完成一个范围可控、可比较、可复现的研究原型。

本仓库同时承担 **Research Project 初稿、PhD Research Proposal 和主项目开发计划书**。中文文档是项目范围与工程决策的主版本；英文 proposal 用于申请和导师讨论，与中文主版本保持一致。

> **当前状态：文档初始化 / 研究与工程设计初稿，2026-10-22。** 尚无运行原型、已测硬件兼容结果、招募数据或伦理批准。文档中的效果、延迟、采样、样本量和时间安排分别是研究问题、待测能力或暂定计划。

## 研究核心与扩展关系

第一年研究核心是 **2–3 人、室内、静坐或站定的对话**：稳定字幕、匿名会话级发言人标识、适当呈现可观察的语音线索，以及让用户知道何时可以忽略、关闭或纠正提示。布局设计通过共同设计和试点形成；主实验在相同字幕层上比较补充线索的呈现策略。

可选扩展关注 **佩戴者自己**：心率或可用 HRV、活动背景、本人选定的手部动作模式与自述是否有助于及时提供用户选择的支持。动作识别、个人意义解释和干预效用分别验证；不会把握拳、心率升高或重复动作直接解释为负面情绪。

长期保留 Idea Book 的双向口译、视觉文字旁注、共享短期上下文、事件触发推理及多设备输出设计。它们不构成首年主实验的完成前提。

## 平台路线

- **优先目标：Meta Ray-Ban Display + 手机。** 无显示屏的 Ray-Ban Meta 可作为部分采集或音频节点，不能独立承担视野内字幕。
- **Apple Watch：可选的本人心率、活动与反馈端。** 数据新鲜度、型号、系统、权限和后台运行必须实测。
- **Meta Neural Band：消费级手势控制与研究级原始 sEMG 分开核对。** 手势事件不等于可读原始肌电，也不等于心率传感器。
- **Jev：可替换的结构化推理候选。** 它不直接决定提示、不替代 ASR 或传感器，也不是 V-JEPA。规则后端必须先可用。
- **首年无需自制光学系统或 PCB。** 原始信号接口不满足时，优先借用研究设备、使用可访问传感器或缩小该扩展的结论。

上述平台事实和访问限制以[平台证据](04-硬件与平台/平台能力与证据.md)为准；具体产品版本会变化，采购与实验前须重新核对。
