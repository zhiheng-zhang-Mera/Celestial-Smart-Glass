# 实机验证与替代路径

状态：拟议验收计划；所有测试目前均为“未执行”。

基准日：2026-10-22。下面的会话长度、次数和性能目标是初始工程规划，不是实测结果、临床标准或厂商保证。

## 1. 验收目标与停止条件

首四周要回答的不是“能否演示所有设想”，而是：在合法访问的实际设备上，能否形成可停止、可回放、能说明失败原因的字幕与可选提示链路。

最小成功条件是稳定显示与明确退出、一个可用输入路线、时间戳可解释、过期输出不误呈现、故障时有可见状态。HR、HRV、连续 EMG 和视觉说话人关联均可独立缺席。

以下任一情况停止相应分支，不通过绕过权限解决：

- 设备、账户或分发许可未确认。
- 人员数据处理未经批准，或无法满足同意撤回和删除要求。
- 无法区分真实采样时刻与接收时刻。
- 停止控制失效、重复恢复旧提示、明显视觉不适或干扰沟通。
- 需要把实验功能包装成正式可发布能力才能继续。

DAT 实验能力的发布限制见 [META-02](https://github.com/facebook/meta-wearables-dat-ios/blob/main/CHANGELOG.md)；具体平台前提见[平台能力与证据](平台能力与证据.md)。

## 2. 每个会话必须留下什么

| 记录组 | 最小记录项 |
| --- | --- |
| 会话与责任 | session_id、开始／结束时间、执行人、测试目的、输入材料授权、结果状态 |
| 设备组合 | 眼镜完整型号、固件、手机型号与系统、手表型号与系统（若使用）、区域与连接方式 |
| 软件与权限 | 应用构建标识、SDK 版本、模型 revision、权限状态、实际使用的实验性功能、获准测试／分发路径 |
| 时钟与数据 | 源时钟域、源起止时间、接收时间、呈现时间、时钟映射方法、估计同步误差、样本年龄 |
| 质量与失效 | 通道／格式、可用质量标记、缺失、重连、丢帧、过期、错误归属、退出与恢复结果 |
| 结果定位 | 通过／不通过／受阻／未执行，受影响能力，最小复现步骤，批准后的精简证据位置 |

公开仓库不存设备序列号、健康原始样本、参与者录音、访问 token 或个人账户截图。审计记录可用不含身份内容的摘要；完整证据存放在经批准的位置。

### 时间记录规则

1. 保留源数据的时间窗口，不以接收时间覆盖源时间。
2. 单设备内部用单调时钟计算耗时；跨设备比较前建立并记录映射。只保存“Unix 时间”不能证明已经同步。
3. 数据年龄按“当前呈现时刻－映射后的源窗口结束时刻”计算；没有可靠映射时将年龄标为未知，不填零。
4. 分别报告：语音到稳定字幕延迟、充分证据到提示延迟、健康样本发布／传递延迟、提示呈现时年龄。
5. 超出该提示经验证的 ttl，或时钟误差已大于允许范围时，抑制该提示；不反复重试旧事件。

以上是本项目的拟议测量协议，不是对厂商时间戳精度的既有确认。

## 3. 四周验收安排

### 第 1 周：权限、显示与控制

建议执行三个相互独立的 20 分钟开发会话，包含冷启动、连接中断和恢复。仅用合成文本或获准材料。

- [ ] 核对实际是 Meta Ray-Ban Display，而非无显示型号；确认配对、开发权限与当前分发路线。
- [ ] 在眼镜上完成中文／目标语言文字更新、长句换行、字幕占位、字符缺失检查和可读性记录。
- [ ] 验证停止、退出和纯字幕入口；手势不可用时仍有可操作的手机端停止控制。
- [ ] 记录焦点、文本刷新、后台／前台切换、断连、重新连接及设备状态变化。
- [ ] 模拟显示与真实眼镜分别标记；不把 MockDisplayKit 截图记为实机显示证据。

**通过门槛**：会话结束后没有残留提示；停止后不继续处理新输入；恢复不重放已过期内容；显示问题有明确复现记录。不能稳定显示时转入明确标注的模拟／替代终端路线。

DAT 的显示与模拟能力依据 [META-01](https://developers.meta.com/wearables/device-access-toolkit/) 和 [META-02](https://github.com/facebook/meta-wearables-dat-ios/blob/main/CHANGELOG.md)，上述会话尚未执行。

### 第 2 周：音频、字幕与说话人归属

使用同一套获准测试材料，依次覆盖单人、两人交替、重叠、静音、背景噪声和未支持语言。先回放，再决定是否进入受控现场。

- [ ] 明确音频来自眼镜、手机、商业麦克风还是预录材料；记录格式、通道与时间戳。
- [ ] 对 SDK 语音与 camera-audio 分支分别核实权限和实验性限制。
- [ ] 不因得到单路音频而宣称取得同步原始麦克风阵列。
- [ ] 字幕区分 provisional 与 committed；后续修订不悄悄变成新的说话人事实。
- [ ] 归属不明输出 unknown；重叠不强制归给一个人；系统不建立跨会话身份库。
- [ ] 输入中断时显示“输入不可用”，而不是继续保留看似新鲜的字幕。

**通过门槛**：能够追踪每条字幕的源窗口、修订与归属；出现未知状态不阻塞暂停；错误和延迟有可复查记录。识别率与可读性阈值在目标语言的先导材料上确定，不预先捏造一个通用准确率。

实验性语音与音频状态依据 [META-02](https://github.com/facebook/meta-wearables-dat-ios/blob/main/CHANGELOG.md)。

### 第 3 周：可选腕部数据，分别验收

**A. Apple Watch HR／可用 HRV**

- [ ] 经明确授权读取实际存在的样本；记录源设备、指标、单位和窗口。
- [ ] 对前台、后台、手机锁屏、连接中断、手表摘下及撤销授权分别测试。
- [ ] 分别统计测量间隔、可观测的发布间隔、接收间隔和 data_age 的分布；不可观测的时刻标为未知。
- [ ] 不从低频 BPM 推算逐搏 HRV，不把 SDNN 与其它 HRV 定义混用，不假定取得原始 PPG。
- [ ] 历史补传只进入回顾，不触发已过期的即时提示；不伪造锻炼会话以获取频率。

Apple 的“最快约 5 秒测量”、研究中的“后台每 30 秒发布至 HealthKit”和应用实际接收不是同一指标。[APPLE-01](https://support.apple.com/en-us/120277)；[APPLE-02](https://www.apple.com/health/pdf/Heart_Rate_Accuracy_Study_2026.pdf)；[APPLE-03B](https://developer.apple.com/documentation/WatchConnectivity)；[APPLE-04](https://developer.apple.com/documentation/healthkit/hkquantitytypeidentifier/heartratevariabilitysdnn)

**B. 消费 Neural Band 命令**

- [ ] 列出实际收到的事件及来源；按确认、暂停、略过等用户主动动作测试。
- [ ] 记录漏触发、误触发、重复事件和用户能否撤销。
- [ ] 不以事件计数代替原始肌肉活动强度或“无意识动作次数”。

**C. 研究 EMG 分支，仅在获得研究访问后执行**

- [ ] 核实 Aria／Neural Band 组合、研究权限、SDK、固件和支持的采集配置。
- [ ] 读取真实 EMG／IMU 样本与校准信息；记录时钟域、批次顺序、缺失及同步方法。
- [ ] 以休息、主动小动作、普通操作等任务建立信号质量基线；佩戴变化后重新检查。
- [ ] 自发行为的标签来自另行批准的观察与用户确认，不能从一次握拳直接生成情绪标签。

消费处理方式见 [META-03](https://www.meta.com/en-gb/blog/meta-ray-ban-display-ai-glasses-connect-2025/)；研究样本流与申请见 [META-04](https://facebookresearch.github.io/projectaria_tools/gen2/ark/client-sdk/changelog)、[META-05](https://ai.meta.com/aria-application/)。

**通过门槛**：每个分支能够独立返回 available、missing、stale 或 unavailable；缺失可选信号不改变基础字幕的含义。不取得研究访问则 C 保持“受阻”，不阻塞核心研究。

### 第 4 周：策略、故障注入与准入复核

- [ ] 用冻结回放材料检验 show、defer、abstain、no_op；最终许可由控制器裁决。
- [ ] 检验 ttl、错误说话人、过期时间、无证据、网络超时、限流、格式异常和模型版本变化。
- [ ] 比较 rules 与已批准的模型后端，保留相同 candidates、evidence 和显示规则。
- [ ] 可选提示失败时停止该提示；基础 ASR 若也失效，明确提示输入不可用，不能声称字幕必然继续。
- [ ] 检查数据流、云端字段、运行日志与清除行为；验证没有未经批准的数据外发。
- [ ] 输出 capability-by-configuration 结论，以及哪些分支只在模拟或实验室设备上通过。

初始工程目标可沿用“充分证据到可选提示的额外延迟 p95 小于 1 秒”，但须先由先导任务确认该提示仍然有用；这是计划目标，不是 Jev、SDK 或网络的时延承诺。每个提示的有效期需单独确定。

## 4. 替代路径与可主张的结论

| 受阻环节 | 优先替代路径 | 必须缩小的主张 |
| --- | --- | --- |
| 消费眼镜显示／测试访问 | 已有且获准的实验室显示设备；其次是手机／桌面／官方模拟预览 | 模拟结果不能证明实际眼镜佩戴效果；另一设备结果不能冒称 Meta 实机结果 |
| 眼镜音频 | 已有手机麦克风、借用商用麦克风、获准预录材料 | 只能评价该输入链路，不能宣称眼镜阵列定位 |
| 说话人关联不稳 | 匿名编号、unknown、受控预标注回放 | 预标注不是实时识别；不能据此报告现场归属准确率 |
| Jev 无审批／离线／超时 | disabled、rules 或已批准的本地替代后端 | 本地替代不是 Jev 离线版；不偷偷改用另一个云服务 |
| Watch 数据过旧或缺失 | 禁用即时生理分支；保留手动状态标记或经同意的回顾 | 不把缺失数据当平静，也不把晚到数据当实时 |
| 只有 Neural Band 命令 | 研究主动确认与导航；连续 EMG 另行申请 | 不能把预定义手势输出称为自由 EMG 监测 |
| 空间定位／眼动未核实 | 固定字幕区、屏幕相对标签与显式偏好 | 不声称世界锁定、眼动自适应或直接测量注意力 |

替代优先复用已有或借用硬件，不为完成概念演示自动采购，更不要求定制 PCB、光学或传感器电子学。

## 5. 从开发到参与者会话

| 阶段 | 必要条件 | 当前状态 |
| --- | --- | --- |
| 开发验证 | 合成／授权材料、访问合法、可停止、日志最小化 | 计划中，未执行 |
| 先导会话 | 机构伦理与数据流批准、可访问沟通支持、工程门槛通过 | 尚未获得本项目完成证据 |
| 现场扩展 | 先导可用、真实失效处理通过、有效期与目标语言阈值冻结 | 不自动承诺 |
| 对外应用分发 | 重新核查平台政策、实验性功能限制、依赖许可与隐私披露 | 不属于本轮实现或发布 |

本仓库文档发布不等于应用分发批准。最终准入由研究负责人和相应审批主体决定；任何失败都可形成有价值的能力边界记录，但不能包装为已实现功能。
