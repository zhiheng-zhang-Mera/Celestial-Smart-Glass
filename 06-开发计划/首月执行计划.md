# 首月执行计划

本计划从实际获准开展工程准备时计算。优先使用已有设备、公开接口与合成 / 明确授权的素材；涉及真实参与者的观察和采集等待相应研究批准。每周完成可审查成果，而不是预设所有平台权限已经到位。

## 第 1 周｜核对条件与最小界面

盘点眼镜具体型号、iPhone / Watch 型号及系统、可用开发账号、借用研究设备、可用电脑和目标语言。依据官方文档建立能力矩阵，记录账号和 SDK 限制，不记录账号口令。讨论研究重点和招募资源，准备伦理及材料清单。

同时制作可操作回放入口：开始、字号 / 位置、仅字幕、暂停和结束。回放使用合成事件，固定标记 simulation / replay；目标是验证界面和状态设计，不用它替代头戴舒适度结论。

**周末产物：**能力矩阵初版、设备 / 数据缺口、两至三个低保真布局、任务 T01 / T02 的复用与文件计划。决定下周是否有条件进入真实 SDK 显示探索，现有无屏眼镜不被误当显示设备。

## 第 2 周｜连接可审计的字幕事件

确定最小事件 schema 和来源 / 时间字段，接入一种合法音频或回放源。实现 / 复用字幕增量修订，匿名发言人可以暂用标明来源的人工回放标签。把未知、断线、过期和清理接到正常入口，记录实际延迟的起止点。

如果目标设备访问允许，验证一条真实文字显示路径；不允许则完成替代终端选择和研究外推边界。源码和研究材料分别保存，不提前创建空的完整服务集群。

**周末产物：**能从 UI 进入的最小回放切片、schema 版本、失败示例、清理检查和设备分支结论。它仍不是完整实时研究原型。

## 第 3 周｜有限提示与可选信号盘点

以经共同设计确认或明确标为待确认的少量词汇，接入观察性 CueCandidate、规则控制器和提示槽。检查用户关闭、证据缺失、旧字幕修订、过期和错配处理。

Apple Watch 与原始肌电分别盘点和试测权限。若只有消费级命令手势，保留控制功能，连续动作支路标记受阻。Jev 先用合成结构化材料评估接口和版本，不上传参与者资料。

**周末产物：**提示生命周期、规则基线、模型适配草案、健康数据 / 肌电可访问性说明。新鲜度、准确率与提示上限只形成候选参数。

## 第 4 周｜复核最小闭环与下一阶段

固定演示构建和合成输入，记录开始 → 字幕 → 提示 → 关闭 → 结束；分别演示无模型、设备断开、未知发言人和数据过旧。核对请求、设备接受与实际呈现的证据级别。

完成第一版协议修订、共创材料、数据管理方案与预算清单。若相应机构尚未批准或资源未落实，继续非参与者的工程与文献工作。将下阶段任务缩到已有证据支持的能力，不通过增加硬件自研来掩盖访问问题。

**周末产物：**阶段交接、可复现 manifest、已知缺口、下一阶段任务和必要资源。目标为一个可审查的最小技术切片与研究准备包；不承诺四周内完成全部算法、招募或实验。
