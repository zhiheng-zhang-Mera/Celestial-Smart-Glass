# 复用与选型

状态：候选与准入规则，不是已安装依赖清单，也不是最终技术选型。

官方来源核查日：2026-10-22。本轮不安装软件、不下载模型、不创建产品实现。

## 1. 原则与优先顺序

优先复用成熟采集、转写、说话人分段和界面基础组件，把项目工作放在事件语义、用户控制、不确定性策略和可复现评估。没有证据表明需要自研的部分，不为展示复杂度而重做。

选型顺序为：合法访问与伦理可用性 → 接口适配 → 目标语言和场景效果 → 时间与故障行为 → 运行资源 → 成本与维护。开源许可、模型权重许可、访问资格和设备分发许可分别检查；其中任何一个成立，都不自动替代其余条件。

核心先完成字幕、会话内说话人标签、unknown 状态与停止／纯字幕控制。HR／HRV、连续 EMG、相机关联和复杂社会推断均不得成为首个可用版本的必经依赖。

## 2. 候选组件与证据

| 层 | 可复用候选／路径 | 已核实事实与官方来源 | 使用前的项目门槛 |
| --- | --- | --- | --- |
| 眼镜显示与输入 | Meta DAT 官方接口与模拟设备 | 兼容眼镜显示接入；部分输入／运动／语音／音频功能实验性。[META-01](https://developers.meta.com/wearables/device-access-toolkit/)；[META-02](https://github.com/facebook/meta-wearables-dat-ios/blob/main/CHANGELOG.md) | 真实型号、固件、目标系统、测试账户、功能级分发限制全部核对 |
| 离线 ASR 基线 | OpenAI Whisper 官方代码与模型 | 官方仓库说明代码和模型权重采用 MIT；标准 transcribe 方法按滑动窗口处理文件。[REUSE-01](https://github.com/openai/whisper) | 固定提交／权重；实测目标语言、资源、静音误输出和增量稳定性，不称其直接提供完整实时字幕产品 |
| 说话人分段 | pyannote.audio 与明确选定的模型 | 工具代码为 MIT；community-1 模型卡标为 CC-BY-4.0，使用说明包含接受条件与访问 token。[REUSE-02](https://github.com/pyannote/pyannote-audio)；[REUSE-03](https://huggingface.co/pyannote/speaker-diarization-community-1) | 代码与每个权重的许可分别留档；取得访问资格；不把 diarization 当作姓名识别 |
| 可选决策 | rules、local-approved、jev-cloud | Jev 基础输入是文本／结构化状态，图像能力另有实验限制。[JEV-01](https://docs.typesafe.ai/models)；[JEV-03](https://docs.typesafe.ai/images) | 使用统一 DecisionProvider 契约；保留 disabled；云数据流与版本冻结先通过 |
| 实验回放／管理面板 | 小型原生界面或 React 候选 | React 官方仓库列为 MIT 的 UI 库。[REUSE-04](https://github.com/react/react) | 手机／桌面面板与眼镜渲染分开；React 可用不代表可原样部署到 DAT 显示 |
| 可选生理数据 | HealthKit／Watch Connectivity | 用户授权与配对应用通信。[APPLE-03A](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data)；[APPLE-03B](https://developer.apple.com/documentation/WatchConnectivity) | 接收年龄、后台限制、撤权与缺失行为实测；没有样本就不启用该分支 |
| 可选连续 EMG | Aria Gen 2 研究接口 | SDK 2.5.0 描述 Neural Band EMG／IMU 批次流。[META-04](https://facebookresearch.github.io/projectaria_tools/gen2/ark/client-sdk/changelog) | 单独研究访问、设备与校准；不是消费 DAT 的默认附加能力 |

这些是比较起点，不要求全部采用。其它 ASR、分段、模型或 GUI 可以替换，但必须提供同等来源、许可、版本和验证证据。当前不指定未经测试的“最佳模型”或性能排名。

## 3. 不应省略的适配层

下面是拟议模块边界，不是已有类库 API；名称和字段在实现阶段与主协议统一。

| 适配层 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| CaptureAdapter | 采集格式、源窗口、时钟域、权限和可用性 | 从设备麦克风数量猜测通道能力 |
| TranscriptProvider | 增量文字、修订标识、稳定片段及所覆盖时间 | 将推断性社会提示写进逐字字幕 |
| SpeakerAttributionProvider | 会话内匿名编号、重叠、unknown 及更新 | 永久声纹档案、姓名推断或未经核实的空间位置 |
| PhysiologicalProvider | 指标名、单位、样本窗口、来源、缺失与数据年龄 | 用低频 BPM 伪造 HRV，或将生理变化直接标成情绪 |
| MotorActivityProvider | 区分消费手势事件、IMU 样本与研究 EMG；保留来源类型 | 将预定义点击当作连续肌肉活动测量 |
| DecisionProvider | 接受 candidates[]／evidence[]，返回有限动作建议和版本 | 取得最终呈现权、外部执行权或无限历史访问 |
| PresentationController | 用户偏好、ttl、占位、有效性、去重与停止 | 用高模型置信度覆盖硬约束 |
| DisplayAdapter | 把已批准内容映射到实际终端，并报告呈现／失败 | 把模拟显示当实机，或把屏幕标签当世界锚点 |

框架适配完成后，先用固定回放和虚拟异常测试契约，再接设备。测试替身只验证软件行为；不得据此报告真实传感器精度或佩戴体验。

## 4. 每项复用都要有可追溯清单

选定时记录以下信息；没有记录的依赖不能进入参与者会话构建：

1. 上游官方地址、包名、明确版本或提交、获取日期。
2. 模型权重的模型卡、revision／摘要、语言和目标域，不仅记录 Python 包版本。
3. 代码、权重、示例、字体／图标和数据各自的许可及署名义务。
4. 传递依赖、解码库、运行时、硬件加速与目标系统兼容性。
5. 下载／使用是否需要接受条款、特定账户或审批；撤销与到期条件。
6. 是否联网、上传什么、是否有遥测、模型下载与运行推理是否可分离。
7. 实测性能、已知失败、维护责任人与可替换路径。
8. 对应用分发、研究数据共享、模型再分发的限制。

例如，pyannote.audio 官方资料描述可配置的遥测。即便推理在本地，也应核对实际配置与网络行为；不能用“开源／本地”推断“没有外发”。[REUSE-02：遥测说明](https://github.com/pyannote/pyannote-audio)

不得把取得访问所需的 token、账户截图、模型权重或受限测试数据提交至公开仓库。遇到 gated 模型，先完成正常授权；不寻找绕过下载门槛的副本。

## 5. 比较协议与淘汰条件

| 对象 | 必须比较的维度 | 淘汰或降级触发 |
| --- | --- | --- |
| ASR | 目标语言字／词错误、静音误输出、修订频率、稳定字幕延迟、资源、失联行为 | 在研究目标场景持续不稳；切换到获准回放或已通过的替代输入 |
| 说话人分段 | 换人、重叠、未知说话人、时间对齐与错误附着 | 归属错误无法可靠暴露；改匿名／unknown 或受控预标注 |
| 决策模型 | 相同候选池下的错误、覆盖率、过期率、延迟、成本和校准证据 | 不优于简单基线，或只有增加风险／外发才可用 |
| GUI／显示 | 字符可读、更新稳定、焦点和停止、布局负担 | 影响基础字幕或退出困难；减少可选提示 |
| 可选腕部信号 | 数据年龄、缺失、佩戴影响、来源语义、目标时间尺度 | 无法支持该提示的时间尺度；改为回顾或禁用 |

比较使用相同的获准材料、目标语言与任务定义，记录机器、系统、版本和冷／热启动条件。用实验室 GPU 跑出的耗时不等于手机速度；离线分段评估不等于实时多人对话。

主 HCI 实验需要尽可能固定字幕、布局、候选池与输入材料。更换 ASR 或分段器可能改变参与者面对的信息，不应未经说明与“提示门控效果”混在一起。

## 6. 如何避免依赖锁死

- 先以协议定义输入、缺失和失效，再挑厂商实现；厂商专有字段留在适配器内。
- 以版本固定的回放材料测试输出，保留 rules 与 disabled 模式。
- 不让可选健康／EMG 连接失败阻塞停止和基本字幕。
- 更换后端必须重新验证概率语义、目标语言、校准与数据流，而非只通过编译。
- 在公开产物中注明上游许可与贡献；“复用成熟工具”是工程选择，不能当成原创算法贡献。

## 7. 现在仍需决定的事项

这些是进入实施前的正式决策项，而不是已完成内容：

- 实际可借用的显示、手机与开发设备组合，以及 iOS／Android 主路线。
- 目标语言、获准的回放集与可接受的字幕修订策略。
- 首个 ASR 和分段基线的版本、权重与运行位置。
- 眼镜终端的官方可用组件，与独立实验管理面板的实现方式。
- Jev 的机构数据处理许可；如果没有，则从 rules 开始。
- 是否确需 Apple Watch／连续 EMG 扩展，以及它们是否回答新增的独立研究问题。
