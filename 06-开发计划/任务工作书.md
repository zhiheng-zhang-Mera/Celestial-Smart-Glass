# 任务工作书

系列：`CEL-SMART-GLASS-20261022-v1`。目标：形成可独立开展第一年研究、并可逐步扩展的商业眼镜沟通辅助项目。

**本次授权范围是完整文档初始化。** T00 属于本次文档任务；T01–T16 是下一阶段可领取的计划，不表示已安装 SDK、购买设备、启动服务或开展研究。

## 1. 统一施工方式

架构采用设备适配 → 明确来源与时间 → 字幕 / 本人信号分路 → 有限上下文 → 可替换模型 → 确定性控制器。候选栈包括 Apple 原生客户端、可审计回放界面与研究分析脚本；正式语言 / 框架按平台审计和复用记录确定。

每项实际开发开始时补齐：授权任务引用、完整基线 SHA、执行环境、可改路径、复用版本 / 许可、输入材料、必要权限和验收记录位置。下列源码路径均为**拟创建路径**，不是已经存在或可运行的模块。关键契约变化先同步受影响任务；无关仓库不修改。

逐项遵循 UI → 正式入口 → 真实能力，不先建设长期没有用户入口的大量后端。纯内部模块接到其上游任务和可观测诊断入口，不为每个函数单独造页面。每个功能检验成功、拒绝、取消、缺失与恢复中有实际风险的路径，避免照抄实现的无意义测试。

## 3. 逐项工作说明

### CSG-T01｜确认能用什么

- **产物 / 文件：**更新 `04-硬件与平台/平台能力与证据.md` 与 `实机验证与替代路径.md`；后续创建 `experiments/platform-audit/README.md`、无敏感内容的配置 manifest。
- **步骤：**盘点型号、OS、权限、显示、音频、命令、HR、EMG、后台与分发；逐项记文档来源、实测结果和缺口。已有商用 / 研究设备优先借用，不先自制硬件。
- **验收：**每条能力有 supported / authorized / verified / available，显示最小文字、可停止和断线状态有证据；未测写 NOT_RUN。无法获得权限不宣告实现失败，改用已说明的替代路线。

### CSG-T02｜先让用户控制回放

- **拟改路径：**`apps/replay-ui/` 的入口、字幕视图、设置和模式标识；`experiments/fixtures/synthetic/` 合成材料。
- **切片：**从首页进入回放，调整字号 / 位置，暂停 / 结束，查看未知发言人、重叠和错误状态。设计稿之后接正式回放入口，始终标明 synthetic / replay。
- **验收：**从正常导航可完成一次开始到清理；布局切换不篡改原始素材；关闭提示后不再新增提示。录运行画面和构建身份，不把它作为实机眼镜证明。

### CSG-T03｜会话与最小契约

- **拟改路径：**`contracts/events/`、`contracts/capabilities/`、`services/session/`、`services/context/` 及客户端状态入口。
- **切片：**进入权限与会话界面 → SessionController → 有来源、修订与时间的事件。实现幂等停止、流重连 epoch、有限缓存和晚到事件拒绝。
- **验收：**撤回权限、重复事件、时钟未知、结束后响应、崩溃重启不会恢复已终止采集；来源与原始值不被解释覆盖。字段样例与实际 schema 一致。

### CSG-T04｜字幕真实接线

- **拟改路径：**`services/perception/asr/`、`services/captions/`、客户端字幕页、`experiments/caption-evaluation/`。
- **切片：**选音频源 → CaptionSession 正式入口 → 固定版本 ASR / 合法语音服务。保留稳定段、可修订尾、关键更正、输入不可用和低质量状态。
- **验收：**获准同一材料的原始输入、稳定字幕、修订与端到端延迟可追溯；无声不生成伪造新话轮。ASR 实际许可、语言与运行位置入档；质量不足可回到研究回放。

### CSG-T05｜说话人、方向与未知

- **拟改路径：**`services/perception/speakers/`、`services/association/`、标签视图和关联诊断入口。
- **切片：**匿名标签 → 归属入口 → 分段 / 聚类 / 可选音画关联；位置字段使用明确坐标系和已证实来源。
- **验收：**换人、离开视野、遮挡、重叠、时钟偏差的错误率与恢复可见；未知合法。人工标签与自动输出分别记录，不以回放正确映射宣称实时关联已验证。

### CSG-T06｜有限线索与最终控制器

- **拟改路径：**`services/cues/`、`services/policy/`、客户端提示 / 解释 / 仅字幕入口、`contracts/decisions/`。
- **切片：**按共同设计词汇展示观察与假设，接入 CueCandidate 和确定性规则。加入 TTL、用户开关、占位、过期、撤销和拒绝原因。
- **验收：**高置信建议也不能绕过关闭 / 缺证据 / 错误关联；旧字幕修订使相关旧提示失效；处理速度不足时降级且不阻塞字幕。

### CSG-T07｜同一输入的三条件比较

- **拟改路径：**`experiments/core-study/materials/`、`experiments/core-study/configs/`、`experiments/core-study/analysis/`、研究运行器界面。
- **切片：**分配参与者临时代码和冻结材料，选择条件，运行相同字幕算法与候选池；随机化与显示事件独立记录。原始资料仍在受控存储，目录只放获准内容与索引规范。
- **验收：**C0/C1/C2 的差异仅为预设补充策略；材料在不同条件间平衡而不让同一人重复答同一题；输入、错误探针和缺失规则可复现。不能因调参改变密度后声称单独验证置信校准机制。

### CSG-T08｜显示适配与实机交付

- **拟改路径：**`apps/iphone/`、`apps/glasses/` 的正式入口与 DeviceAdapter；实际可用 SDK 类型在 T01 后确定。
- **切片：**设备状态 / 预览 / 停止 → DisplaySession → 真实显示和反馈回执。有限显示支持不足时选择已记录的替代终端。
- **验收：**目标型号实际显示、输入、退出、前后台和重连；记录温度 / 电池与会话时长。模拟器、手机和真实镜片显示分别存证，不能互相替代。

### CSG-T09｜Jev 可替换集成

- **拟改路径：**`services/decision/providers/`、`contracts/decisions/`、模型状态 / 云开关入口及 `experiments/model-evaluation/`。
- **切片：**disabled / rules / local-approved / jev-cloud → DecisionProvider → 固定版本最小请求与受限输出。先 rules，后经允许的 Jev；不假定可下载 Jev 权重。
- **验收：**版本、字段、成本和时限可查；格式异常、权限、429、过期、模型漂移和无网有明确结果。相同冻结事件下比较校准、覆盖、错误与延迟，无增益可使用较简单后端。

### CSG-T10｜本人手表信息

- **拟改路径：**`apps/watch/`、`apps/iphone/health/`、`services/self-awareness/`、本人设置 / 手动标记入口。
- **切片：**独立授权与样本状态 → Watch / PhoneBridge → 带观察与送达时间的可用指标。区分连续 / 间歇 / 历史补传；手动支持优先可用。
- **验收：**数据旧、摘表、锁屏、断连和撤权不会触发伪实时提示；指标定义正确；无 BPM→伪 HRV 计算。后台不得用虚假用途绕过平台限制。

### CSG-T11｜个人动作与日常支持

- **拟改路径：**`services/self-awareness/motor/`、`apps/iphone/daily/`、`experiments/self-awareness/`。
- **切片：**用户选择模式和动作 → 分开的 MotorEvent / CommandGesture 通道 → 获准传感器。加入活动负例、跨日校准、静默、拒绝和本人意义纠正。
- **验收：**仅手势 API 时不声称连续 EMG；无害动作不自动列为问题；云端不默认收健康原始流；按小时误提示、实际佩戴与缺失有分母。没有增量价值可以停止该支路。

### CSG-T12｜研究执行与分析

- **文件：**`05-实验与评估/` 协议和版本记录；后续 `experiments/core-study/` 的材料、随机化、去标识分析脚本与合成复现样例。
- **切片：**伦理与可访问招募 → 共创 → 离线评估 → 试点 → 参数冻结 / 注册 → 主实验 → 分析。设计阶段的共创早于 T07；受控主实验必须等待冻结版本。
- **验收：**主要结果和 C2vsC0 对比预先写明；参与者 / 题目重复测量、缺失、偏离和二次比较有记录；零效果可如实报告，不事后更换主指标。

### CSG-T13｜隐私与可复现交付

- **拟改路径：**`services/session/cleanup/`、诊断入口、`experiments/manifests/`、隐私文档和数据目录说明。
- **切片：**可查看实际采集 / 上传 / 保存状态，主动结束、删除与诊断；每次运行绑定代码、模型、数据和配置版本。
- **验收：**日志默认无敏感正文；停止、异常、缓存、重试队列、备份与外部请求的处理可核查；仅能删除应用副本的范围明确。公共仓库与受控数据分开。

### CSG-T14｜口译扩展

- **拟改路径：**`services/translation/`、`services/audio-output/`、多输出模式 UI。
- **切片：**一个 semantic_unit、一个版本化译文；先一种语言对与一个输出，再增加双向路由、TTS speculative 队列、播放回执和本地耳返候选。
- **验收：**语义提交、否定 / 转折错误、不可回滚输出、停播和回声回灌；实际语言质量与延迟分别报告。系统输出不重新成为外部输入。

### CSG-T15｜视觉文字扩展

- **拟改路径：**`services/visual-text/`、文字选区 / 旁注 UI、`contracts/anchors/`。
- **切片：**真实可用的手动 / 视野中心 / 眼动选择 → ROI → OCR → TextAnchor，随后多帧与强模型按需升级。
- **验收：**来源文字与补全分开，原文可见，锚点失效清理、位置漂移、遮挡和计算收益实测；无 6DoF 时不宣称世界锁定。

### CSG-T16｜可选保存与 Celestial 服务

- **拟改路径：**明确需求后增加 `services/integrations/`，以及保存 / 导出 / 服务状态 UI；不预先引入整套 Agent 框架。
- **切片：**自愿个人概览或一个获准远端计算调用；手机拥有权限、停止与数据目的。外部服务不可用不扩大上传范围。
- **验收：**服务发现、授权、目标执行、返回及被手机实际消费分别有证据；没有这些证据不称为已挂载运行。没有外部主机仍可运行已实现的核心功能。
